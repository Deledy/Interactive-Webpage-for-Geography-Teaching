## 0. 一句话结论

P4 实施时**偏离定稿方案**：没有接入已验证的 SunEditor 块编辑器，而是手写了一个基于已废弃 `document.execCommand` 的替代品（存在死按钮、高亮吞格式等硬伤）；分栏在编辑端存在但**渲染端缺 CSS**，预览与课程里竖向堆叠，等于没实现。另按最新需求裁剪表单字段、收敛题型。返工分三块：**换内核（§3）、补分栏渲染（§4）、裁表单与运行时（§5/§6）**。

## 2. 修正后的数据契约

### 2.1 题目字段最小集

```js
// 选择题（固定单选）
{
  id: 'm1q1',
  type: 'choice',
  material: '<p>…材料 HTML…</p><div class="cq-cols">…</div>',  // 富文本块编辑器产出
  stem: '题干纯文本',
  options: [{ key: 'A', text: '…' }, /* … */],
  answer: 'B',                       // 单个字母（不再支持数组/多选）
  analysis: '<p>…解析 HTML…</p>'     // 富文本块编辑器产出
}

// 主观题
{
  id: 'm1q2',
  type: 'essay',
  material: '…HTML…',
  stems: ['（1）…', '（2）…'],        // 设问，纯文本，一行一问
  referenceAnswer: '…HTML…',         // 参考答案（富文本）
  analysis: '…HTML…'                 // 解析（富文本）
}
```

### 2.2 删除项与兼容策略

| 项 | 编辑器 | 运行时 | 数据 |
| --- | --- | --- | --- |
| `source` | 删控件、删模板字段 | 删 `cq-q__source` 徽章渲染（renderCard L136、L194） | 死键，不迁移 |
| `mode` | 删下拉，模板固定 `answer` 为单字母 | `modeOne` 逻辑保留（遗留数据兼容），徽章分支保留但永远走「单选题」 | 死键，不迁移 |
| `knowledge` | 删两个控件 | 删 `cq-block--knowledge` 渲染分支（renderCard L105-116） | 死键，不迁移 |
| `criteria` | 删控件，`lines` 模式随之整体删除 | 删 `cq-block--criteria` 渲染分支（renderCard L173-179） | 死键，不迁移 |
| `groupTitle/groupIntro` | 删分组表单控件（L712 一带） | 无涉 | 无涉 |

- 分组名一律以**结构清单**（课程 `index.html` 抽取结果）为准，编辑器不再提供覆盖字段。
- `richText.js` 的 `mode:'lines'` 仅服务于 criteria，criteria 删除后**该模式整体移除**。

## 3. 富文本内核替换（问题 6a · 核心）

### 3.1 选型（锁定，不再留给实施者）

**SunEditor 3.3.3（MIT 许可）**，按 `spikes/material-editor-spike/index.html` 已验证的块模型接入。

- 引入方式：优先 npm（`AGENTS.md` 第 11 条），Vite 构建内联进单文件产物；若 v3 的 ESM 入口与 Vite 单文件插件冲突，退回 spike 路径——`vendor/suneditor.min.js + suneditor.min.css + zh_cn.js` 放 `editor/src/vendor/`，`<script>` 引入后用 `window.SUNEDITOR`（spike 已验证离线可用）。
- 删除 `richText.js` 整个文件及 `editor.css` 中 `ce-rich__*` 全部样式（保留 `ce-rich-mount` 挂载点类名可复用）。

### 3.2 SunEditor v3 的三个坑（spike 实证，必须照做）

1. **插件必须显式传**：`SUNEDITOR.create(el, { plugins: [SUNEDITOR.plugins.fontColor, …], buttonList: [...] })`——v2 的自动注册已废除。
2. **图片默认宽度要在创建后注册**：`editor.$.pluginManager.register('image', null, { defaultWidth: 300 })`（顶层 `image:{}` 选项无效）。单位 px，保证缩放走像素路径。
3. **取值用 `editor.$.html.get()` / 设值 `editor.$.html.set(html)`**，不是 v2 的 `getContents`。

### 3.3 块模型（照抄 spike，逐条落地）

材料、解析、参考答案三类字段 = **块序列**：

```
文本块   = 1 个 SunEditor 实例
分栏块   = 2 或 3 个独立 SunEditor 实例并排（flex 容器 + 虚线边界）
```

- 底部按钮：`+ 文本块 / + 两栏 / + 三栏`；每块右上角「删除此块」（confirm 后 `editor.destroy()` 并移除 DOM）。
- 序列化：按 DOM 顺序取各实例 HTML → 空块跳过（含 `<img>/<table>` 不算空）→ 分栏块包成 `<div class="cq-cols"><div class="cq-col">…</div>…</div>` → 每段过 `sanitizeHtml` → 段间拼接。
- 反序列化：解析已有 HTML 时只认**顶层** `cq-cols` 节点拆分栏块，其余归入文本块（spike `parseBlocks` 逻辑）。
- 工具栏（与 spike 一致，精简版）：
  `undo redo | bold underline italic strike | fontColor backgroundColor | list_bulleted list_numbered | table image | removeFormat | codeView`
- 语言包：`zh_cn`（`window.SUNEDITOR_LANG.zh_cn`）。
- 图片：不配上传地址 → 自动 base64 内联（离线分发可用）；默认宽 300px；渲染端 `max-width:100%` 兜底。

### 3.4 与现有编辑器的对接

- 保留 `richAreaHtml` 的「可见编辑器 + 隐藏 textarea 承担 `data-path` 读写」桥接模式（`main.js` L602-609、L778-800），只把挂载点里创建的东西从手写编辑器换成 §3.3 的块模型。
- `enhanceRichFields()` 在每次表单渲染后调用（现状 L815 已如此），重建前先 `destroy()` 全部 SunEditor 实例。
- 窗口 `beforeunload` 与块删除时确保 `destroy()` 被调用，防监听器泄漏（spike 承重假设，浏览器实测通过）。

### 3.5 已知交互特性（写进编辑器内置说明，不做 shim）

| 现象 | 原因 | 给教师的说明文案 |
| --- | --- | --- |
| 图片选中（蓝框）时按回车只会取消选中，不换行 | SunEditor 上游设计：Enter 先 `componentDeselect` | 「点图片旁边的文字，再按回车」 |
| 单元格单击=选格、拖动=选区，打字即恢复编辑 | SunEditor v3 Excel 式表格交互 | 「点进格子后直接打字」 |

## 4. 分栏渲染补齐（问题 6b）

`content/card.css` 追加（数值可与既有卡片风格微调，结构必须一致）：

```css
/* ---------- 材料分栏（编辑器 cq-cols 契约） ---------- */
.cq-cols { display: flex; gap: 18px; margin: 10px 0; }
.cq-col { flex: 1; min-width: 0; overflow-x: auto; }
.cq-col img { max-width: 100%; height: auto; }
.cq-col table { max-width: 100%; }
@media (max-width: 720px) { .cq-cols { flex-direction: column; } }
```

- `content/sanitize.ts` 已按 `cq-` 前缀放行类名（注释 L7），`div` 在标签白名单内——补一条**单元测试**锁定：`<div class="cq-cols"><div class="cq-col">…` round-trip 不被剥。
- 渲染端不需要解析分栏结构（纯 CSS 表达），`renderCard.ts` 无需改动分栏相关逻辑。
