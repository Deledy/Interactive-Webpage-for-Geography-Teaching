# 画布 + 题目槽 · 一屏一题（第四轮）

> 文档日期：2026-10-31
> 适用模块：`shared/quiz`（内容层 / 运行时 / 编辑器）与课程侧练习题入口
> 本轮定位：**推翻第三轮“每题一个画布块”的做法**，回到“一张画布 + 一个题目槽 + 组内切题”的模型。

### 修订记录

| 轮次 | 重点 | 状态 |
|---|---|---|
| 第一轮 | v3 题组 / 自由布局材料 / 统一渲染 | 已实现 |
| 第二轮 | 画布交互修复 + `question` 题目对象 + canvas/step 模式 | 已实现，本轮部分作废 |
| 第三轮 | 删除画布外题目表单，题目全部进画布、就地编辑 | 已实现，**“每题一块”模型作废** |
| 第四轮（本文档） | 一题组一画布；画布内只有材料 + **一个题目槽**；组内上一题/下一题切换槽内内容；组末进入下一组画布 | 已实现 |

> 两项确认已落地：① 题目槽可拖动 / 缩放；② 组内最后一题点「下一题」直接进入下一组画布。

---

## 0. 需求复述与结论

1. **一个题组 = 一张画布**。切换题组就是换一张全新画布，上一组的画布不再出现。
2. 画布负责**材料排版**：文字、图片、表格自由摆放，确定相对位置，渲染成一张整齐的“纸”。
3. 画布上**有且只有一个题目占位符（题目槽）**，不是每道题一块。
4. 题组内的所有题（2 道选择题 + 1 道综合题…）**共用这个槽**。编辑器里「上一题 / 下一题」，槽内内容替换，画布不动。
5. 课程端**一屏一题**：画布固定 + 槽内当前题；点下一题只换槽内题；组内最后一题再点下一题 → **直接进入下一组画布**。
6. 不再有「画布整页 / 逐题」双模式，只有一个模型。
7. 题目槽**允许拖动与缩放**（老师决定题目在纸上的位置和大小）。

一句话：**画布是纸，槽是卷面位置，题是槽里的内容；翻题不换纸，翻组才换纸。**

---

## 1. 结构总览

```text
题组 1（= 画布 1）
└── 画布
    ├── 文字对象 / 图片对象 / 表格对象        ← 材料，自由摆放
    └── 题目槽（唯一）                       ← 可拖动 / 缩放
        └── 当前题（第 i 题）                ← 组内所有题轮流占用

题组 2（= 画布 2）
└── 画布（全新，互不影响）
```

- 画布尺寸仍为逻辑尺寸（默认 1000×520，可随内容增高）；
- 题目槽默认放在材料下方，整宽；
- 槽内题目高度超出槽时，优先自动增高槽与画布；老师手动调过尺寸则保留。

## 2. 数据模型（v5）

### 2.1 画布对象

`MaterialObject` 只保留三类 + 一个槽：

```ts
interface SlotMaterialObject extends BaseMaterialObject {
  type: 'slot'
  /** 选项排列（flow / free），属于该题组的题目呈现方式 */
  optionLayout?: OptionLayout
}
type MaterialObject = TextMaterialObject | ImageMaterialObject | TableMaterialObject | SlotMaterialObject
```

约束：

- 一个 `materialLayout` 中 **最多一个** `slot`；多余的在载入时丢弃并记录 issue；
- 一个题组有题目时**必须有** slot（编辑器载入时自动补）；
- slot 只保存矩形与选项排列，不引用任何题目。

### 2.2 题组

```ts
interface CqGroup {
  id?: string
  title?: string
  layout?: 'stacked' | 'split'      // 旧字段，保留兼容，不再影响画布
  materialLayout?: MaterialLayout | null
  questions: CqQuestion[]           // 题库：组内全部题目，顺序即翻题顺序
}
```

- `renderMode` **删除**；
- `questionId` / `QuestionMaterialObject` **删除**；
- 当前编辑到第几题只存在编辑器内存（按题组 `_k` 记录），不落盘。

### 2.3 版本

- `window.__PRACTICE_DATA__.version = 5`；
- 运行时继续读取 v3 / v4，并在校验阶段转换为 v5 结构（见 §6）。

## 3. 编辑器

### 3.1 界面

```text
题组 1                                   [上下][左右]（旧字段，仅兼容）
┌ 工具条 ─────────────────────────────────────────────────────────────┐
│ 撤销 重做 | +文字 +图片 +表格 | +插入题目 | 层级 对齐 复制 删除      │
│           | 属性栏位置  预览作答  缩放                               │
├ 画布 ───────────────────────────────────────────────────────────────┤
│ 材料文字 / 表格 / 图片                                               │
│ ┌ 题目槽（可拖动 / 缩放）──────────────┐                             │
│ │ 第 2 / 3 题   [上一题] [下一题]      │                             │
│ │ 06 单选题                            │                             │
│ │ 题干（画布内直接改）                 │                             │
│ │ A …  B …  C …  D …（点选项直接改）   │                             │
│ │ 解析 ▸                               │                             │
│ └──────────────────────────────────────┘                             │
├ 属性栏（随选中对象切换）─────────────────────────────────────────────┤
│ 子题目：第1题 第2题 第3题  ＋新增题  复制  删除                      │
│ 题型：选择题 / 主观题 | 显示题号                                     │
│ 题干与选项 / 设问与参考答案 / 解析                                   │
└──────────────────────────────────────────────────────────────────────┘
```

- 画布只渲染**当前题**；
- 槽顶部有轻量的「第 i / n 题 · 上一题 / 下一题」条，点击即切换（不弹窗、不动画布）；
- 槽为空（题组暂无题）时显示「还没有题目，点击 + 插入题目」。

### 3.2 插入题目

- 工具条唯一入口 `+ 插入题目`：
  1. 在 `group.questions` 末尾追加一道选择题（A/B/C/D，答案 A）；
  2. 若画布还没有槽，按「材料下方 24、整宽」创建槽；
  3. 切换到新题（槽内容替换），题干输入框聚焦；
  4. **画布不新增对象、不重复出现题目块**。
- 属性栏「＋ 新增题」等价；默认与当前题同题型。

### 3.3 切题

- 槽内「上一题 / 下一题」：在组内循环（首题上一题置灰，末题下一题置灰，因为组末要交给课程端的“下一组”）；
- 属性栏「子题目」chips：点第 N 题直接切过去；
- 切换只替换槽内 DOM，不重建画布、不改变材料对象位置；
- 切题不写撤销快照（不是数据修改）。

### 3.4 槽的拖动与缩放

- 槽与文字 / 图片 / 表格共用同一套选中框、顶部移动条、四角缩放柄；
- 槽不允许删除（只能删除题目数据）；槽不可复制；
- 槽的位置尺寸写入 `layout.objects`，随题库一起保存。

### 3.5 槽内编辑

沿用第三轮已实现的画布内编辑：

- 题干 / 设问 / 选项文本：单击进入光标编辑，Enter 提交、Esc 退出；
- 选项单击选中 → 属性栏对应行高亮；✓ 徽标设置正确答案；
- 主观题「编辑参考答案」在槽内展开富文本编辑区；
- 解析在槽内折叠展开，与属性栏同步；
- 内容变高时自动增高槽，必要时增高画布。

### 3.6 属性栏

| 分组 | 内容 |
|---|---|
| 子题目 | 第 1…N 题 chips、＋新增题、复制当前题、删除当前题 |
| 题型 | 选择题 / 主观题（切换前确认，切换可撤销） |
| 选择题 | 题干、选项列表（文本 / 正确 / 删除 / 新增）、排列 1/2/3 列 |
| 主观题 | 设问（每行一条）、参考答案 |
| 解析 | 独立文本域 |
| 布局 | 选中槽：X / Y / 宽 / 高 / 层级；选中材料对象：原有属性 |

- 删除题目：删数据；若删到 0 道，槽保留并显示空态提示；
- 撤销快照 = `{ layout, questions, activeIndex }`，删题可撤销；
- 属性栏默认吸底，可切右侧（记忆偏好），保留第三轮实现。

## 4. 运行时（课程 / 预览）

### 4.1 页面序列

把全部题组展开成页面：

```ts
pages = [
  { group, question, questionIndex, globalIndex }, // 组1 第1题
  { group, question, questionIndex, globalIndex }, // 组1 第2题
  ...
  { group, question, questionIndex, globalIndex }, // 组2 第1题
  ...
]
```

- **逐题模式（默认，浮层）**：一屏一页 = 画布（材料）+ 槽内当前题；上一题 / 下一题在页面序列上前后移动，**跨组自动衔接**（组1 最后一题 → 组2 第一题，即换画布）；
- **列表模式**：同样的页面纵向堆叠（每页一张画布 + 一道题），用于页内嵌入；
- 顶部进度显示「题组 x / y · 第 i / n 题」，题号点阵仍按题。

### 4.2 槽内作答

- 槽内渲染 `renderQuestionObject(view)`：选项按钮带 `data-cq-opt` / `data-key`，沿用现有事件委托；
- 判定后槽内显示判定条与解析；
- 综合题「查看参考答案」在槽内展开；
- 重做：清空作答状态，回到第 1 组第 1 题。

### 4.3 旧数据兜底

没有 `slot` 的题组（v3/v4）：沿用“材料 + 题目卡片”的旧渲染，不影响存量课程；编辑器保存后自动升级为 v5。

## 6. 迁移（v3 / v4 → v5）

载入（编辑器与运行时校验）统一执行：

1. 删除 `materialLayout.objects` 中所有 `type:'question'` 的对象；
2. 若题组有题目且没有 slot：在“最后一个材料对象底部 + 24”插入一个整宽 slot；
3. 若 slot 数量 > 1：只保留第一个；
4. `renderMode` 丢弃；
5. 题目补齐稳定 id（同题组唯一）；
6. 编辑器保存时写 `version: 5`。

## 7. 校验与安全

```text

```

## 9. 验收场景

1. **一画布一槽**：题组插入 3 道题，画布上始终只有 1 个题目槽，材料对象位置不变。
2. **切题**：槽内点「下一题」，题号/题干/选项整体替换，画布与材料不动；到第 3 题「下一题」置灰。
3. **插入**：点「+ 插入题目」→ 题目追加、自动切到新题、画布对象数不变。
4. **编辑**：槽内点选项直接改文字；点 ✓ 设正确答案；属性栏同步高亮。
5. **主观题**：槽内「编辑参考答案」展开填写；解析折叠可编辑。
6. **拖动缩放**：槽可拖动、可缩放，位置随题库保存。
7. **课程逐题**：一屏一页；组内切题不换画布；组末点下一题进入下一组，画布整体更换。
8. **列表模式**：页面纵向堆叠，每题一页。
9. **迁移**：打开 v4 数据，旧题目块被清掉、自动补 1 个 slot，题目全部保留；保存为 v5。
10. **存量课程**：无 slot 的旧题组仍按“材料 + 卡片”渲染。

## 10. 风险与不做的事

| 风险 | 处理 |
|---|---|
| 槽内题目过高撑破画布 | 自动增高槽 + 画布；手动尺寸优先；画布可滚动 |
| 组内题目很多导致翻题成本 | 顶部「第 i / n 题」+ 键盘左右键切换 |
| 旧数据里题目对象残留 | 载入统一 strip，保存不再写 |
| 列表模式每页重复画布，体积变大 | 单页画布只在当前页面渲染；列表模式按需渲染（先实现简单版） |

不做：任意角度旋转、多页分页、选项拖出槽、画布外题目面板。
