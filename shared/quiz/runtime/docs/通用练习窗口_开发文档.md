# 通用练习窗口 · 开发文档

> 本文档描述一个**与课程无关、可跨课复用**的练习窗口组件 `PracticeWindow`：点击「练习」弹出浮层，支持选择题判定、答案解析、材料关键词高亮，并通过**主题令牌**做到「换课只改令牌、不改组件代码」。

| 项目 | 内容 |
| --- | --- |
| 功能名称 | 通用练习窗口（`PracticeWindow`） |
| 定位 | 跨课复用的练习渲染组件 + 主题层；统一承载「模块随堂练习」与「课后练习」 |
| 文档版本 | v1.2 |
| 状态 | 已实现（核心 S1–S5 + 计时/限时/逐题模式 + 浮层 `openPracticeWindow`（**居中大窗口 + 强毛玻璃遮罩**）+ **左材料 / 右上题目 / 右下说明** + `theme` 令牌覆盖；M3 拖拽不接入） |
| 最近更新 | 2026-10-26 · 视觉重构：浮层改为**居中大窗口 + 高模糊毛玻璃遮罩**；单题改为**左材料 / 右上题目（含选项或参考答案） / 右下说明**；浮层默认**逐题模式 + 自动计时 + 关闭按钮** |

## 1. 背景与目标

**观察到的现状：** 项目里存在两套彼此独立、且与单课代码耦合的练习实现。

| | 模块随堂练习（M1–M9） | 课后练习（M10） |
| --- | --- | --- |
| 载体 | 模态浮层 [practiceModal.ts](../../../../lessons/geo01-earth-universe/src/modules/practiceModal.ts) | 页内区块 [customQuiz.ts](../../../../lessons/geo01-earth-universe/src/modules/customQuiz.ts) |
| 题型 | 单选（点选即判）+ M3 拖拽 | 单选 / 多选 / 综合题 |
| 数据结构 | `PracticeQuestion`（`q` / `options: string[]` / `answer: number` / `explain`） | `CqQuestion`（`stem` / `options:{key,text}[]` / `analysis` / `knowledge` / `criteria`） |
| 样式 | [customQuiz.css](../../../../lessons/geo01-earth-universe/src/styles/customQuiz.css) 与浮层样式分散、类名前缀不同 | 同左 |
| 与课程耦合 | 样式直接引用本课设计令牌，逻辑直接 import 本课 `lessonData` | 数据已外置，但渲染逻辑仍在本课源码 |

**受影响的人与时机：** 需要为**新课**做练习窗口的老师/开发者——必须重写或大改渲染与样式，才能让练习窗口看起来属于这门课。

**产品决策：** 抽出三层解耦的通用组件——

1. **数据层**：沿用已定稿的统一 schema（`CqQuestion` / `__PRACTICE_DATA__`），不新造格式；
2. **组件层**：`PracticeWindow` 只负责渲染与交互，不认识任何具体课程；
3. **主题层**：颜色、圆角、字体、间距全部走 **`--pw-*` 令牌**，令牌默认值映射到课程已有令牌，新课只覆盖令牌即可换风格。

**可观察结果：** 接入新课程时，只需 ① 提供一份符合 schema 的数据文件，② 按需覆盖一份 `--pw-*` 令牌；**不修改组件代码**，练习窗口即与课程视觉一致。

## 3. 组件模型

```
课程页面（index.html）
   │  .practice-btn[data-practice]  （M1–M9）
   │  #quiz-custom-body            （M10，页内）
   ▼
接入适配层（课程侧，薄）
   │  openPracticeWindow({ data, container, theme, options })
   ▼
PracticeWindow（shared/quiz/runtime/，与课程无关）
   ├─ 渲染器：HTML 白名单清洗 + 纯文本转义（无 Markdown）
   ├─ 交互状态机：选择 / 提交 / 判定 / 展开答案
   ├─ 导航与进度、计时、全屏
   └─ 消费 --pw-* 令牌（默认映射到课程令牌）
   ▼
DOM（浮层容器 或 页内容器）
```

**关键设计：一份渲染器，两种容器。** 组件对外暴露 `openPracticeWindow(...)`（浮层 / 页内挂载一体）与底层 `createPracticeView(...)`（仅渲染与交互，供自定义外层容器复用）：

- **M1–M9 模块随堂练习** → 不传 `container`，由组件自建浮层容器（弹出窗口，符合用户诉求；页面不再自带 `#practice-modal`）；
- **M10 课后练习** → 传入 `#quiz-custom-body` 作 `container`，页内挂载（保留现有导航「练习」入口体验）。

> 采用「同一渲染器 + 可配置容器」而非「统一改成弹窗」，是为了在不破坏 M10 现有导航入口的前提下统一渲染与数据。默认保留 M10 页内形态（见 §10 决策 3）。

## 4. 功能需求

功能需求是本文档主体。为避免重复，跨功能共用的规则（Markdown、高亮、状态、版本）在 §5 统一定义。

### FR-01 触发与开关

- **触发**：点击页面 `.practice-btn[data-practice="<键>"]`；或由课后练习入口调用页内挂载。
- **处理规则**：
  - 按 `<键>` 查询数据源对应题目集；命中则打开窗口并渲染；
  - 未命中数据 → 打开窗口并展示空态（FR-10），不报错、不影响页面。
- **结果与状态**：窗口打开时页面滚动锁定（`body` 溢出隐藏）；关闭时恢复；同一时刻只允许一个窗口打开。
- **关闭方式**：关闭按钮、`Esc`（全屏浮层铺满视口，无遮罩可点）。
- **异常**：渲染过程抛错 → `try/catch` 回退空态（FR-10）。

### FR-02 窗口骨架

布局区域与职责：

```
┌────────────────── 全屏强毛玻璃遮罩（模糊 + 压暗，遮挡背景） ──────────────────┐
│  ┌──────────────────── 居中大窗口（约 1560 × 900） ────────────────────┐  │
│  │ 标题 / 引导语                        第 3 / 8 题   ⏱ 04:37   [×]   │  │
│  ├────────────────────────────────┬────────────────────────────────────┤  │
│  │  左栏：材料                     │  右上：题目                         │  │
│  │  材料（含高亮关键词）            │  题号 / 题型 + 题干 + 选项           │  │
│  │                                │  综合题：设问 + 「查看参考答案」      │  │
│  │                                │          + 参考答案                 │  │
│  │                                ├────────────────────────────────────┤  │
│  │                                │  右下：说明（判定 / 正确答案 / 解析） │  │
│  ├────────────────────────────────┴────────────────────────────────────┤  │
│  │ [上一题] [下一题]                                   [重做本页练习]   │  │
│  └─────────────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 遮罩：铺满视口，`backdrop-filter` 高模糊 + 深色压暗，明显遮挡后方页面内容。
- 窗口：居中大窗口（带圆角 / 描边 / 投影），超出视口时整体可滚动；≤1024px 时贴满视口并上下堆叠。
- 顶部：标题 + 引导语（数据 `subtitle` / `intro`）+ 进度 + 计时 + 关闭按钮；页内挂载（M10）另提供「全屏」按钮。
- 进度：仅当题目数 > 1 时显示；逐题模式在顶部显示「第 x / n 题」，列表模式显示题号点阵。
- 题目区：**左材料 / 右上题目 / 右下说明**；浮层逐题模式下无材料时保留较窄左栏（给出「本题无阅读材料」提示），列表 / 页内模式无材料时退化为单栏。
- 底部：逐题模式下为「上一题 / 下一题」，右侧为重置入口（`resetBar: false` 可隐藏）。

### FR-03 选择题

- **触发**：窗口内点击某个选项。
- **处理规则**：
  - **单选**：点击即锁定，立即判定；
  - **多选**：点击为勾选/取消，需点「提交答案」才判定；未选任何项时提交按钮禁用；
  - 判定时：正确项标绿、被错选项标红、其余项降噪；同时展示判定条与「正确答案」。
- **结果与状态**：判定后该题选项不可再改（选项 `disabled`）；显示解析（若有）。
- **交互流**：选择 → 判定 → 展示答案与解析 → 进入下一题或重置。
- **字段**：取决于统一 schema（§6）：`stem`、`options[]`、`answer`（单个选项字母）、`analysis`；`mode` 仅为遗留多选数据保留，编辑器不再产出。
- **异常**：字段不完整的题目在渲染前被丢弃并记录（§5.4）。

### FR-04 材料关键词高亮

- **触发**：材料 / 解析等富文本中出现 `<mark class="cq-hl">关键词</mark>`。
- **处理规则**：由内容层白名单清洗后原样渲染；同一段可含多处；可嵌套在加粗、列表、表格单元格内。
- **结果**：视觉上突出关键信息，颜色走 `--pw-blue-soft` / `--pw-accent-text` 令牌。
- **边界**：未使用 `cq-hl` 类名的 `<mark>` 不套用高亮样式，但仍保留语义标记。

### FR-05 综合题

- **触发**：展示含设问的综合题。
- **处理规则**：初始仅显示材料与设问；点「查看参考答案」后，参考答案在**右上题目区**（设问下方）展开，解析说明落在**右下说明区**；再点为「收起」。
- **状态**：`revealed` 每题为独立记忆；与选择题共用同一窗口状态容器。

### FR-06 逐题导航与进度

- **触发**：窗口内点击题号点阵中的某题；或滚动到某题。
- **处理规则**：
  - 显示「第 x / n 题」与题号点阵；
  - 点阵项状态：未作答 / 已作答 / 当前題；
  - 点击点阵项定位到对应题目（列表模式滚动定位；逐题模式切换当前题）。
- **结果**：进度随作答实时更新；当前题与点阵高亮同步。
- **边界**：题目数为 1 时不显示进度栏。
- **实现补充**：题号点阵仅在**列表模式**显示；**逐题模式**在顶部显示「第 x / n 题」，题间切换用底部「上一题 / 下一题」按钮，且**不自动跳题**。浮层默认使用逐题模式。

### FR-07 计时（课堂节奏）

- **触发**：窗口配置 `timer: true`（如 M1–M9 浮层）。
- **处理规则**：打开窗口即开始**正计时（自动累加）**，以 `mm:ss` 显示；**不设倒计时、无到期锁定**。
- **结果与状态**：`reset()` 只清空作答状态，不重置计时（沿用组件默认）。

### FR-08 全屏沉浸

- **触发**：浮层容器默认即**居中大窗口**（无需额外操作）；页内挂载（M10）可由顶部「全屏」按钮临时铺满视口。
- **处理规则**：遮罩层 `position: fixed` + 全视口 + `backdrop-filter: blur(var(--pw-backdrop-blur))`（高模糊）叠加深色压暗，明显遮挡背景内容；窗口本体居中，限制最大宽高，内部按需滚动。
- **结果**：窗口内保留标题栏、进度/计时与「左材料 / 右上题目 / 右下说明」；页内挂载退出全屏后回到页内尺寸。

### FR-09 主题令牌化（复用核心）

- **触发**：组件渲染。
- **处理规则**：组件内**不写死任何颜色/圆角/字体**，全部引用 `--pw-*` 令牌；`--pw-*` 默认为「课程已有令牌」（见 §7）。
- **结果**：新课只要提供 `--gold`/`--cyan` 等基础令牌即自动适配；风格差异大的课程，只需在 `.pw` 作用域覆盖若干 `--pw-*` 即可换肤，**不改组件代码**。

### FR-10 空态与容错

- **触发**：数据文件缺失 / 解析失败 / 无有效题目 / 渲染异常。
- **处理规则**：
  - 文件缺失或无有效题目 → 「本节课暂未配置练习」空态；
  - 结构损坏 → 丢弃非法题、渲染有效题；无有效题时显示「数据格式有误，已忽略」并列出前若干条问题；
  - 渲染异常 → `try/catch` 回退空态。
- **结果**：任何情况都不白屏、不影响窗口外的页面内容。
- **来源**：沿用现有 [customQuiz.ts 校验与空态](../../../../lessons/geo01-earth-universe/src/modules/customQuiz.ts#L338-L523) 行为。

## 5. 共享规则

### 5.1 富文本（HTML）

题库字段直接存 HTML，运行时不再解析 Markdown：

| 字段类型 | 处理 |
| --- | --- |
| 含标签的内容（材料 / 解析 / 参考答案等） | 经白名单清洗后输出 |
| 纯文本（教师直接输入） | 转义后按空行分段（块级）/ 仅转义（行内），**不解释 Markdown** |
| 题干 / 选项 / 设问 / 知识归纳标题 / 分节标题 | 纯文本，仅转义 |

白名单：标签限 `p br strong em u s sub sup mark code a img ul ol li table thead tbody tr th td figure figcaption h3 h4`；属性限图片地址与替代文字、链接地址、表格合并格、段落对齐、图片宽度；类名仅保留 `cq-` 前缀；脚本、样式表、内嵌框架、事件属性一律剥除。实现见 `shared/quiz/content/sanitize.ts`。

### 5.2 关键词高亮

- 写法：`<mark class="cq-hl">关键词</mark>`（在题库中直接写 HTML）。
- 样式取 `--pw-blue-soft` 与 `--pw-accent-text`。

### 5.3 作答状态机

每题状态由 `{ selected, submitted, revealed }` 三态驱动（沿用现有实现）：

| 题型 | 触发 | 状态迁移 | 结果 |
| --- | --- | --- | --- |
| 单选 | 点选项 | `selected=[k]`, `submitted=true` | 判定 + 解析 + 知识归纳 |
| 多选 | 勾选项 | `selected` 增删 | 仅高亮选中态；「提交」可用 |
| 多选 | 提交 | `submitted=true` | 判定 + 解析 + 知识归纳 |
| 综合题 | 查看/收起 | `revealed` 翻转 | 展开 / 收起参考答案块 |
| 任意 | 重置 | 全部清空 | 回到初始态 |

判定正确性：单选比较单键；多选比较集合相等（与顺序无关）。

### 5.4 数据校验与版本

- 逐题校验：选择题需「题干 + ≥2 选项 + 有效答案（答案键须落在选项内）」；综合题需「设问或参考答案」；非法题丢弃并记录问题。
- 版本：数据 `version` 高于组件支持上限 → 仅提示、不阻断。
- 兼容：新增字段一律可选；未知字段忽略。

## 6. 数据模型

**数据层完全沿用已定稿的统一 schema（`lessons/<课>/public/quiz-editor/practice-data.js`，见《自定义练习题模块_开发文档》§18），本组件不新造格式。**

```ts
// 题目（与 src/types.ts 的 CqQuestion 一致）
type CqQuestion = CqChoice | CqEssay

interface CqChoice {
  type: 'choice'
  mode?: 'single' | 'multiple'   // 遗留数据兼容；编辑器只产出单选
  source?: string                // 遗留死键，不再渲染
  material?: string              // 材料（HTML，支持 <mark class="cq-hl">）
  stem: string                   // 题干
  options: { key: string; text: string }[]
  answer: string | string[]      // 单字母 'A'；数组仅遗留多选数据
  analysis?: string
  knowledge?: { title?: string; items?: string[] }  // 遗留死键，不再渲染
}

interface CqEssay {
  type: 'essay'
  source?: string
  material?: string
  stems?: string | string[]
  referenceAnswer?: string
  analysis?: string
  criteria?: string[]            // 遗留死键，不再渲染
}
```

**窗口级入参**（组件对外接口，新增；与题目数据分离）：

```ts
interface PracticeWindowOptions extends PracticeViewOptions {
  data?: CqData | null      // 题库数据（统一 schema）；未显式传 sections 时按其 sections 渲染
  container?: HTMLElement   // 缺省 = 内置浮层容器；传入则页内挂载
  display?: 'overlay' | 'inline' | 'embedded'
                            // 展示形态：铺满视口 / 只挂题目内容 / 铺满指定画布（编辑器预览）
}

interface PracticeViewOptions {
  title?: string              // 顶部标题；缺省「练习」
  subtitle?: string           // 顶部引导语（行内富文本：HTML 清洗 / 纯文本转义）
  sections?: CqSection[]      // 分节题目（课后练习用）
  questions?: CqQuestion[]    // 单组题目（模块随堂练习用；与 sections 二选一）
  mode?: 'list' | 'step'      // 列表模式（默认）/ 逐题模式
  timer?: boolean             // 正计时（自动累加）
  limitSeconds?: number       // 限时秒数：倒计时显示（不锁定、不阻断）；优先于 timer
  fullscreen?: boolean        // 顶部「全屏」按钮
  closable?: boolean          // 顶部「关闭」按钮（浮层用）
  resetBar?: boolean          // 底部「重做本页练习」入口
  theme?: Record<string, string>  // --pw-* 令牌覆盖，形如 { '--pw-accent': '#E8B04B' }
}
```

> 说明：`mode`、`limitSeconds` 属**窗口行为配置**，不写入题目数据文件，避免污染教师可编辑的内容；建议由课程侧在打开时传入。

## 7. 主题令牌契约（换肤机制）

组件样式全部消费 `--pw-*` 令牌。**默认值只作中性兜底，不再映射课程令牌**；真实课程与编辑器预览都以该课显式配色表为准：

- 每课提供 `src/styles/quiz-theme.css`，写最终色值（不引用课程其它变量）；
- 主课程在 `src/main.ts` 引入该文件；构建时另复制一份到 `dist/quiz-editor/quiz-theme.css` 供离线编辑器读取；
- 构建校验检查必需令牌是否齐全，缺项报错，不允许静默回退。

```css
/* shared/quiz/runtime/styles/default-tokens.css —— 中性兜底（组件自带） */
:where(.pw, .pw-overlay) {
  --pw-accent: #ffd54f;
  --pw-success: #66bb6a;
  --pw-radius-card: 16px;
  --pw-overlay-bg: rgba(3, 6, 18, 0.72); /* 遮罩：强毛玻璃压暗 */
  --pw-backdrop-blur: 34px;
  /* …其余令牌同样写中性值 */
}
```

`default-tokens.css` 使用 `:where(.pw, .pw-overlay)`，优先级为 0；遮罩 / 窗口的毛玻璃令牌因此也能作用在 `.pw` 之外的浮层骨架上。课程配色表的 `.pw` 无论加载先后都能覆盖卡片内部令牌。

课程配色表示例（课程侧）：

```css
/* lessons/<课>/src/styles/quiz-theme.css */
.pw {
  --pw-accent: #FFD54F;
  --pw-accent-2: #4FC3F7;
  --pw-radius-card: 12px;
  /* …§6.2 要求的全部令牌 */
}
```

**约束**：组件代码内不得出现具体色值/尺寸字面量，一律走令牌；`npm run check` 会校验配色表必需令牌。

## 10. 已确认设计决策

| # | 决策 | 结论与理由 |
| --- | --- | --- |
| 1 | **与现有实现的关系** | **统一成一套通用组件**，替换 `practiceModal` 与 `customQuiz` 的**渲染层**；两处只保留数据加载与入口。理由：避免两套交互与样式长期漂移。 |
| 2 | **关键词高亮方式** | **手写标注 `==关键词==`**。精确可控、零误伤，天然契合现有 Markdown 子集渲染。 |
| 3 | **容器形态** | 组件支持「浮层」与「页内」两种容器，**同一渲染器**；M1–M9 用浮层，M10 保持页内以不破坏现有导航入口。 |
| 4 | **数据格式** | **不新造**，沿用《自定义练习题模块_开发文档》§18 的统一 schema 与 `__PRACTICE_DATA__`。 |
| 5 | **本轮新增功能范围** | 纳入：逐题导航（列表模式题号点阵）、计时（**正计时，自动累加**，非倒计时）、逐题模式（**不显示进度条**，仅计时器，**不自动跳题**）。**未做**：全屏沉浸、作答小结、键盘快捷键、练习闭环、打印/导出。 |
| 6 | **换肤机制** | `--pw-*` 令牌默认映射课程令牌；逐课覆盖令牌即可换肤，不改组件代码。 |
