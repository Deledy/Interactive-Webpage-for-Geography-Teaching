1. 动态标签页堆叠卡片 dynamic-tabbed-stack-deck

components/dynamic-tabbed-stack-deck.html

2. 3D 透视悬停倾斜卡片堆叠 3d-perspective-hover-tilt-stack

文件
components/3d-perspective-hover-tilt-stack.html
用途
交互式 3D 倾斜卡片堆叠（重点概念强调、封面式知识卡片、课堂演示开场等）
实现
CSS @property 注册变量 + 原生 JS（pointermove 驱动倾斜，rAF 节流），零外部依赖
兼容性
oklch / color-mix 主色内置十六进制降级，旧浏览器自动回退；prefers-reduced-motion 下停用动效
定制
复制进单课时改脚本顶部 CFG 配置；iframe 嵌入时可用 URL 参数覆盖文案与主色
查看调用方式 
<!-- 方式一：整页 iframe 嵌入（样式完全隔离，推荐） -->
<iframe src="../../shared/components/3d-perspective-hover-tilt-stack.html"
        style="width:100%;height:480px;border:0"></iframe>

<!-- 方式二：抽取 CSS + HTML 片段复制进课程页面，改脚本顶部 CFG 配置即可换文案与主色
     注意：保留 .phts 前缀，避免与页面其它组件样式冲突 -->

<!-- 方式三：iframe 用 URL 参数覆盖文案与主色（中文需 URL 编码） -->
<iframe src="../../shared/components/3d-perspective-hover-tilt-stack.html?title=Earth%20Motion&accent=oklch(0.7%200.16%20220)"
        style="width:100%;height:480px;border:0"></iframe>

3. 图片查看器 image-lightbox

文件
components/image-lightbox.html
用途
点击图片弹出查看大图，支持缩放/拖拽/手势操作
实现
原生 JS（Pointer Events + Touch Events + rAF 节流），零外部依赖
兼容性
全现代浏览器，移动端双指缩放支持；prefers-reduced-motion 降级；CSS 变量可覆写主题
查看调用方式 
<!-- 方式一：iframe 嵌入页面（推荐，样式隔离） -->
<iframe src="../../shared/components/image-lightbox.html"
        style="width:0;height:0;border:0;position:absolute;visibility:hidden"
        aria-hidden="true"></iframe>

<!-- 给页面中需要点击放大的图片添加 data-lightbox 属性即可 -->
<img src="photo.jpg" data-lightbox alt="描述">

<!-- 方式二：JS API 手动调用 -->
<script>ImageLightbox.open('图片URL', '描述文字');</script>

<!-- 方式三：复制 <style> + <template> + <script> 内容到页面中 -->

4. 深空玻璃目标卡片 glass-goal-card

文件
components/glass-goal-card.html
用途
封面/开场的学习目标卡片，也可复用为通用玻璃清单卡片（学习要点、课堂任务等）
实现
纯 CSS（backdrop-filter 玻璃拟态 + 悬停微交互），零 JavaScript 依赖
兼容性
配色全部 hex/rgba，无 oklch，天然兼容旧浏览器；prefers-reduced-motion 下停用动效
定制
复制进单课时保留 .ggc 前缀；通过 CSS 变量整体覆写玻璃面/描边/恒星金主色
查看调用方式 
<!-- 方式一：整页 iframe 嵌入（样式完全隔离，推荐） -->
<iframe src="../../shared/components/glass-goal-card.html"
        style="width:100%;height:480px;border:0"></iframe>

<!-- 方式二：抽取 .ggc__* CSS + HTML 片段复制进课程页面，替换标题与条目文案即可
     注意：保留 .ggc 前缀，避免与页面其它组件样式冲突；条目末尾图标可省略 -->
