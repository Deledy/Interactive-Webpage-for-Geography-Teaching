# 通用练习窗口 · 开发文档

> 本文档描述一个**与课程无关、可跨课复用**的练习窗口组件 `PracticeWindow`：点击「练习」弹出浮层，支持选择题判定、答案解析、材料关键词高亮，并通过**主题令牌**做到「换课只改令牌、不改组件代码」。

| 项目 | 内容 |
| --- | --- |
| 功能名称 | 通用练习窗口（`PracticeWindow`） |
| 定位 | 跨课复用的练习渲染组件 + 主题层；统一承载「模块随堂练习」与「课后练习」 |
| 文档版本 | v1.0 |
| 状态 | 设计定稿，待开发 |
| 最近更新 | 2026-10-13 · 初稿（基于 `shared/custom-quiz-editor/docs/自定义练习题模块_开发文档.md` 与现状代码整理） |
| 关联文档 | 《自定义练习题模块_开发文档》（统一 schema / 契约三件套，本文档数据层直接沿用，不另造格式） |
| 组件位置 | `shared/practice-window/` |

## 1. 背景与目标

**观察到的现状：** 项目里存在两套彼此独立、且与单课代码耦合的练习实现。

| | 模块随堂练习（M1–M9） | 课后练习（M10） |
| --- | --- | --- |
| 载体 | 模态浮层 [practiceModal.ts](../../../lessons/geo01-earth-universe/src/modules/practiceModal.ts) | 页内区块 [customQuiz.ts](../../../lessons/geo01-earth-universe/src/modules/customQuiz.ts) |
| 题型 | 单选（点选即判）+ M3 拖拽 | 单选 / 多选 / 综合题 |
| 数据结构 | `PracticeQuestion`（`q` / `options: string[]` / `answer: number` / `explain`） | `CqQuestion`（`stem` / `options:{key,text}[]` / `analysis` / `knowledge` / `criteria`） |
| 样式 | [customQuiz.css](../../../lessons/geo01-earth-universe/src/styles/customQuiz.css) 与浮层样式分散、类名前缀不同 | 同左 |
| 与课程耦合 | 样式直接引用本课设计令牌，逻辑直接 import 本课 `lessonData` | 数据已外置，但渲染逻辑仍在本课源码 |

**受影响的人与时机：** 需要为**新课**做练习窗口的老师/开发者——必须重写或大改渲染与样式，才能让练习窗口看起来属于这门课。

**产品决策：** 抽出三层解耦的通用组件——

1. **数据层**：沿用已定稿的统一 schema（`CqQuestion` / `__PRACTICE_DATA__`），不新造格式；
2. **组件层**：`PracticeWindow` 只负责渲染与交互，不认识任何具体课程；
3. **主题层**：颜色、圆角、字体、间距全部走 **`--pw-*` 令牌**，令牌默认值映射到课程已有令牌，新课只覆盖令牌即可换风格。

**可观察结果：** 接入新课程时，只需 ① 提供一份符合 schema 的数据文件，② 按需覆盖一份 `--pw-*` 令牌；**不修改组件代码**，练习窗口即与课程视觉一致。

## 3. 组件模型

```
课程页面（index.html）
   │  .practice-btn[data-practice]  （M1–M9）
   │  #quiz-custom-body            （M10，页内）
   ▼
接入适配层（课程侧，薄）
   │  openPracticeWindow({ data, container, theme, options })
   ▼
PracticeWindow（shared/practice-window/，与课程无关）
   ├─ 渲染器：Markdown 子集 + ==关键词高亮==
   ├─ 交互状态机：选择 / 提交 / 判定 / 展开答案
   ├─ 导航与进度、计时、全屏
   └─ 消费 --pw-* 令牌（默认映射到课程令牌）
   ▼
DOM（浮层容器 或 页内容器）
```

**关键设计：一份渲染器，两种容器。** 组件对外只暴露一个 `openPracticeWindow(...)`（及其 `mount` 页内挂载变体）：

- **M1–M9 模块随堂练习** → 挂到浮层容器（弹出窗口，符合用户诉求）；
- **M10 课后练习** → 挂到页内容器（保留现有 `#quiz-custom-body` 与顶部导航「练习」入口体验）。

> 采用「同一渲染器 + 可配置容器」而非「统一改成弹窗」，是为了在不破坏 M10 现有导航入口的前提下统一渲染与数据。默认保留 M10 页内形态（见 §10 决策 3）。

## 4. 功能需求

功能需求是本文档主体。为避免重复，跨功能共用的规则（Markdown、高亮、状态、版本）在 §5 统一定义。

### FR-01 触发与开关

- **触发**：点击页面 `.practice-btn[data-practice="<键>"]`；或由课后练习入口调用页内挂载。
- **处理规则**：
  - 按 `<键>` 查询数据源对应题目集；命中则打开窗口并渲染；
  - 未命中数据 → 打开窗口并展示空态（FR-10），不报错、不影响页面。
- **结果与状态**：窗口打开时页面滚动锁定（`body` 溢出隐藏）；关闭时恢复；同一时刻只允许一个窗口打开。
- **关闭方式**：关闭按钮、点击遮罩、`Esc`。
- **异常**：渲染过程抛错 → `try/catch` 回退空态（FR-10）。

### FR-02 窗口骨架

布局区域与职责：

```
┌───────────────────────────────────────────────┐
│ 标题                     [全屏] [关闭]         │  顶部
├───────────────────────────────────────────────┤
│ 第 3 / 8 题   ① ② ③ ④ ⑤ ⑥ ⑦ ⑧     ⏱ 04:37   │  进度/导航/计时
├───────────────────────────────────────────────┤
│  材料（含高亮关键词）                          │
│  题干 ……                                       │
│  [ A … ] [ B … ]                              │  题目区（可滚动）
│  判定条 / 解析 / 知识归纳 / 参考答案           │
├───────────────────────────────────────────────┤
│ [重做本页练习]                                 │  底部状态栏
└───────────────────────────────────────────────┘
```

- 顶部：标题（数据 `title`）+ 全屏、关闭按钮。
- 进度栏：仅当题目数 > 1 时显示（FR-06）；计时条仅当配置限时时显示（FR-07）。
- 题目区：唯一滚动区域。
- 底部：重置入口。

### FR-03 选择题

- **触发**：窗口内点击某个选项。
- **处理规则**：
  - **单选**：点击即锁定，立即判定；
  - **多选**：点击为勾选/取消，需点「提交答案」才判定；未选任何项时提交按钮禁用；
  - 判定时：正确项标绿、被错选项标红、其余项降噪；同时展示判定条与「正确答案」。
- **结果与状态**：判定后该题选项不可再改（选项 `disabled`）；显示解析与知识归纳（若有）。
- **交互流**：选择 → （多选：提交）→ 判定 → 展示答案与解析 → 进入下一题或重置。
- **字段**：取决于统一 schema（§6）：`mode`（single/multiple）、`stem`、`options[]`、`answer`、`analysis`、`knowledge`。
- **异常**：字段不完整的题目在渲染前被丢弃并记录（§5.4）。

### FR-04 材料关键词高亮

- **触发**：材料 / 题干 / 解析等富文本中出现 `==关键词==` 标注。
- **处理规则**：渲染为 `<mark class="pw-hl">关键词</mark>`；同一段可含多处；标注可嵌套在加粗、列表、表格单元格内。
- **结果**：视觉上突出关键信息，颜色取 `--pw-accent-2`（默认映射课程 `--cyan`）。
- **边界**：未闭合的 `==`（如 `==半开`）按普通文本原样输出，不吞掉后续内容。

### FR-05 综合题

- **触发**：展示含设问的综合题。
- **处理规则**：初始仅显示材料与设问；点「查看参考答案」展开参考答案、解析、评分标准；再点为「收起」。
- **状态**：`revealed` 每题为独立记忆；与选择题共用同一窗口状态容器。

### FR-06 逐题导航与进度

- **触发**：窗口内点击题号点阵中的某题；或滚动到某题。
- **处理规则**：
  - 显示「第 x / n 题」与题号点阵；
  - 点阵项状态：未作答 / 已作答 / 当前題；
  - 点击点阵项定位到对应题目（列表模式滚动定位；逐题模式切换当前题）。
- **结果**：进度随作答实时更新；当前题与点阵高亮同步。
- **边界**：题目数为 1 时不显示进度栏。

### FR-07 计时 / 限时（课堂节奏）

- **触发**：窗口配置了 `limitSeconds`。
- **处理规则**：打开窗口即开始倒计时，显示 `mm:ss`；剩余 60 秒内以 `--pw-warn` 强调。
- **到期行为**：**[Assumption, TBD]** 到期后自动提交当前已作答项、未作答项标为「未作答」并直接展开正确答案与解析，窗口进入只读（不可再改答案）。是否可手动开始/暂停、是否仅在逐题模式启用，见 §12。
- **结果与状态**：倒计时结束触发一次锁定；重置练习是否重置计时见 §12。

### FR-08 全屏沉浸

- **触发**：点击顶部「全屏」按钮。
- **处理规则**：**优先**用 CSS 将窗口面板铺满视口（`position: fixed` + 全视口），隐藏页面其余内容；浏览器 Fullscreen API 作为可选增强（`file://` 下可用，需由用户点击手势触发，本按钮点击即为手势）。
- **结果**：窗口内仅保留进度栏与题目区；退出全屏恢复到浮层尺寸。

### FR-09 主题令牌化（复用核心）

- **触发**：组件渲染。
- **处理规则**：组件内**不写死任何颜色/圆角/字体**，全部引用 `--pw-*` 令牌；`--pw-*` 默认为「课程已有令牌」（见 §7）。
- **结果**：新课只要提供 `--gold`/`--cyan` 等基础令牌即自动适配；风格差异大的课程，只需在 `.pw` 作用域覆盖若干 `--pw-*` 即可换肤，**不改组件代码**。

### FR-10 空态与容错

- **触发**：数据文件缺失 / 解析失败 / 无有效题目 / 渲染异常。
- **处理规则**：
  - 文件缺失或无有效题目 → 「本节课暂未配置练习」空态；
  - 结构损坏 → 丢弃非法题、渲染有效题；无有效题时显示「数据格式有误，已忽略」并列出前若干条问题；
  - 渲染异常 → `try/catch` 回退空态。
- **结果**：任何情况都不白屏、不影响窗口外的页面内容。
- **来源**：沿用现有 [customQuiz.ts 校验与空态](../../../lessons/geo01-earth-universe/src/modules/customQuiz.ts#L338-L523) 行为。

## 5. 共享规则

### 5.1 Markdown 子集

沿用现有自研渲染器（[customQuiz.ts](../../../lessons/geo01-earth-universe/src/modules/customQuiz.ts#L42-L164)），**新增 keyword 高亮**：

| 语法 | 输出 |
| --- | --- |
| `**加粗**` / `*斜体*` | `<strong>` / `<em>` |
| `` `代码` `` | `<code>` |
| `![说明](路径)` / `[文字](链接)` | `<img>` / `<a target="_blank">` |
| GFM 表格 | `<table>` |
| `- ` / `1. ` 列表 | `<ul>` / `<ol>` |
| `==关键词==`（**新增**） | `<mark class="pw-hl">` |
| 段落、行内换行 | `<p>` + `<br>` |

**实现要点**：先 HTML 转义，再做行内替换；高亮在行内阶段处理，且**不匹配跨行**（避免误吞）。

### 5.2 关键词高亮

- 语法：`==关键词==`（手写标注，精确可控、零误伤）。
- 渲染：`<mark class="pw-hl">`，样式取 `--pw-accent-2`。
- 未闭合标注按普通文本处理。

### 5.3 作答状态机

每题状态由 `{ selected, submitted, revealed }` 三态驱动（沿用现有实现）：

| 题型 | 触发 | 状态迁移 | 结果 |
| --- | --- | --- | --- |
| 单选 | 点选项 | `selected=[k]`, `submitted=true` | 判定 + 解析 + 知识归纳 |
| 多选 | 勾选项 | `selected` 增删 | 仅高亮选中态；「提交」可用 |
| 多选 | 提交 | `submitted=true` | 判定 + 解析 + 知识归纳 |
| 综合题 | 查看/收起 | `revealed` 翻转 | 展开 / 收起参考答案块 |
| 任意 | 重置 | 全部清空 | 回到初始态 |

判定正确性：单选比较单键；多选比较集合相等（与顺序无关）。

### 5.4 数据校验与版本

- 逐题校验：选择题需「题干 + ≥2 选项 + 有效答案（答案键须落在选项内）」；综合题需「设问或参考答案」；非法题丢弃并记录问题。
- 版本：数据 `version` 高于组件支持上限 → 仅提示、不阻断。
- 兼容：新增字段一律可选；未知字段忽略。

## 6. 数据模型

**数据层完全沿用已定稿的统一 schema（`lessons/<课>/public/practice-data.js`，见《自定义练习题模块_开发文档》§18），本组件不新造格式。**

```ts
// 题目（与 src/types.ts 的 CqQuestion 一致）
type CqQuestion = CqChoice | CqEssay

interface CqChoice {
  type: 'choice'
  mode?: 'single' | 'multiple'   // 默认 single
  source?: string                // 题源标注
  material?: string              // 材料（富文本，支持 ==高亮==）
  stem: string                   // 题干
  options: { key: string; text: string }[]
  answer: string | string[]      // 单选 'A'；多选 ['A','C']
  analysis?: string
  knowledge?: { title?: string; items?: string[] }
}

interface CqEssay {
  type: 'essay'
  source?: string
  material?: string
  stems?: string | string[]
  referenceAnswer?: string
  analysis?: string
  criteria?: string[]
}
```

**窗口级入参**（组件对外接口，新增；与题目数据分离）：

```ts
interface PracticeWindowOptions {
  title?: string            // 顶部标题；缺省「练习」
  container?: HTMLElement   // 缺省 = 内置浮层容器；传入则页内挂载
  mode?: 'list' | 'step'    // 列表模式（默认）/ 逐题模式
  limitSeconds?: number     // 限时；缺省不限时
  theme?: Partial<Record<string, string>>  // 可选：--pw-* 令牌覆盖
}
```

> 说明：`mode`、`limitSeconds` 属**窗口行为配置**，不写入题目数据文件，避免污染教师可编辑的内容；建议由课程侧在打开时传入。

## 7. 主题令牌契约（换肤机制）

组件样式全部消费 `--pw-*` 令牌；令牌默认值**映射到课程已有令牌**，因此：

- **已按项目令牌体系设计的课程**：无需任何额外配置即自动适配；
- **风格差异大的课程**：只覆盖 `--pw-*` 即可换肤。

```css
/* shared/practice-window/styles/default-tokens.css —— 默认映射（组件自带） */
.pw {
  --pw-surface:      var(--glass-bg, rgba(255,255,255,.06));
  --pw-border:       var(--glass-border, rgba(255,255,255,.14));
  --pw-accent:       var(--gold, #FFD54F);      /* 正确答案 / 当前题 / 重点 */
  --pw-accent-2:     var(--cyan, #4FC3F7);      /* 材料 / 关键词高亮 / 链接 */
  --pw-success:      var(--success, #66BB6A);   /* 判定正确 */
  --pw-error:        var(--error, #EF5350);     /* 判定错误 */
  --pw-warn:         var(--warn, #FFB74D);      /* 计时告警 */
  --pw-text:         var(--text-main, #E8EAF6);
  --pw-text-dim:     var(--text-dim, rgba(232,234,246,.7));
  --pw-radius-card:  var(--radius-card, 12px);
  --pw-radius-btn:   var(--radius-btn, 8px);
  --pw-font:         var(--font-sans, system-ui, sans-serif);
  --pw-fs-body:      var(--fs-body, 20px);
  --pw-fs-note:      var(--fs-note, 16px);
  --pw-dur:          var(--dur, .35s);
  --pw-ease:         var(--ease, cubic-bezier(.25,.8,.35,1));
}
```

新课换肤示例（课程侧）：

```css
/* lessons/<新课>/src/styles/practice-window-theme.css */
.pw { --pw-accent: #E8B04B; --pw-accent-2: #2FB6A8; --pw-radius-card: 16px; }
```

**约束：组件代码内不得出现具体色值/尺寸字面量**，一律走令牌；`npm run check` 可增加该项静态检查（见 §9）。

## 9. 构建与校验集成

- 组件源码在 `shared/` 下作为单一真源，各课通过构建/别名引入，**不复制副本**（与 `shared/custom-quiz-editor` 同一模式）。
- `npm run check`（结构校验）建议新增两项：
  1. 组件样式文件不得出现硬编码色值（`#rgb`/`rgb(` 等字面量），一律经令牌；
  2. 组件不得 import 任何 `lessons/**` 路径（防止反向耦合）。

## 10. 已确认设计决策

| # | 决策 | 结论与理由 |
| --- | --- | --- |
| 1 | **与现有实现的关系** | **统一成一套通用组件**，替换 `practiceModal` 与 `customQuiz` 的**渲染层**；两处只保留数据加载与入口。理由：避免两套交互与样式长期漂移。 |
| 2 | **关键词高亮方式** | **手写标注 `==关键词==`**。精确可控、零误伤，天然契合现有 Markdown 子集渲染。 |
| 3 | **容器形态** | 组件支持「浮层」与「页内」两种容器，**同一渲染器**；M1–M9 用浮层，M10 保持页内以不破坏现有导航入口。 |
| 4 | **数据格式** | **不新造**，沿用《自定义练习题模块_开发文档》§18 的统一 schema 与 `__PRACTICE_DATA__`。 |
| 5 | **本轮新增功能范围** | 仅纳入：逐题导航/进度、计时/限时、全屏沉浸。**作答小结与键盘快捷键不做**（用户明确）；练习闭环、打印/导出不做。 |
| 6 | **换肤机制** | `--pw-*` 令牌默认映射课程令牌；逐课覆盖令牌即可换肤，不改组件代码。 |
