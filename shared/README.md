# shared/ 共享资源目录

存放所有单课都可能复用的公共内容，按类型分目录存放：

| 子目录 | 用途 |
| --- | --- |
| `components/` | 公共组件（通用卡片、提示框、按钮、全屏按钮等） |
| `styles/` | 通用 CSS（字体、变量、布局、按钮样式） |
| `utils/` | 通用 JS 工具函数 |
| `assets/` | 公共图标、字体、封面元素等静态资源 |
| `templates/` | 可复用的页面片段模板 |

## 使用说明

1. 只有"多课复用"的资源才放这里；单课专用资源放在该课的 `assets/` 下。
2. 单课引用 `shared/` 资源时，使用相对路径 `../../shared/...`（注意目录层级）。
3. 后续可在此基础上建立统一的封面、导航、练习弹窗等共享组件。
4. 当前为增量迁移，先建立目录规范，资源按需逐步抽离。
