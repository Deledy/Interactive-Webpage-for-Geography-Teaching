# 技术实现交接包

## 1. 技术路线总览
- 实现形式：**单课 Vite 工程**（`index.html` 入口 + `src/` 分层），构建产物为单文件内联 HTML（项目既定分发模式）
- 推荐技术栈：TypeScript + 原生 DOM + CSS 变量 + **SVG 自绘图形** + **GSAP**（项目已有依赖，用于补间/时间线）+ **Three.js**（项目已有依赖，仅用于 M4-子 线速度演示的三维地球）
- 明确不引入：图表库（只有一条对比条，不需要）、图片资源（除 M5 地图数据外全部矢量自绘）；**地图库例外**：M5 中国地图经教师确认（2026-09-19）使用 `echarts`（按需引入）+ 本地内联的 DataV.GeoAtlas 数据，见 §5.4
- 三维使用边界：仅 M4-子 一处；贴图由 `CanvasTexture` 运行时程序化生成，**不引入任何外部贴图/模型/数据文件**；必须有 `detectWebGL()` 兜底与 `dispose()`（含 `forceContextLoss()`）释放
- 是否依赖外部库：允许，只用 `gsap`、`three` 与 `echarts`（后者仅 M5 地图渲染）；其余自研
- 是否支持离线：**必须**（严禁远程 URL；字体/任何资源本地化）
- 是否优先移动端适配：**否**（用户明确"不必兼容手机"）；目标环境为**教室投屏 1280×720 ~ 1920×1080**，并向下兜底 1024×768

## 3. 页面结构建议
- 建议 DOM 结构（一屏一个 `<section class="screen">`，纵向滚动 + 锚点导航）：

```html
<body>
  <header class="nav" id="nav">…M0…</header>
  <main class="deck">
    <section class="screen" id="m1">…</section>
    <section class="screen" id="m2">…</section>
    <!-- m3 … m8 -->
  </main>
  <div class="toast-host" id="toastHost" aria-live="polite"></div>
  <div class="overlay-host" id="overlayHost"></div> <!-- 完成特效层，挂载即插入、播放完即移除 -->
</body>
```

- 模块组织顺序：M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8（与教学流程 S1–S8 一一对应）
- 是否需要锚点导航：**需要**（M0），且每个 `<section>` 用 `scroll-margin-top` 补偿固定导航高度
- 是否需要状态管理：需要**极轻量集中状态**（一个 store + 订阅），不做框架。理由：M0 进度点、M5 完成计数、M7 表格行需要跨模块读同一份数据源
- 是否需要本地数据对象：**必须**。所有教学内容（表 1、表 2、7 条条件、四基地映射、练习题、综合题材料与参考答案）集中在 `src/data/lessonData.ts`，组件只读不写死文案

## 4. 样式组织建议
- 是否使用 CSS 变量：**是**。在 `:root` 定义色彩/字号/间距/动效时长（与 02 文档视觉系统一一对应），并提供：
  - `[data-theme="projector"]`：投影增强（浅底高对比）配色覆盖
  - `@media (prefers-reduced-motion: reduce)`：关闭所有补间，改为直接呈现终态
- 响应式断点建议：**只做两档**——`≥1440px`（正常）、`1440px ~ 1024px`（整体缩放：容器 `zoom`/`transform: scale` + 字号不缩，保证投影最小 20px）。不写手机断点
- 卡片/按钮/提示框统一类名建议：
  - `.panel`（HUD 面板，含四角角标）、`.angle-tag`（角度标签）、`.cond-card`（条件卡）、`.base-box`（基地框）、`.sentence-card`（句子卡）、`.answer-table`（答题表格）
  - 状态类统一为 `is-*`：`is-active` / `is-done` / `is-correct` / `is-wrong` / `is-revealed` / `is-disabled`
  - 反馈类统一为 `feedback--ok` / `feedback--err` / `feedback--info`
- 动效实现建议：
  - 时长令牌：`--t-fast:150ms`（状态切换）、`--t-base:300ms`（常规）、`--t-slow:600ms`（揭示/扫描）、`--t-hero:1200ms`（仅 M1）
  - 缓动令牌：`--e-out: cubic-bezier(.2,.8,.2,1)`、`--e-back: cubic-bezier(.34,1.56,.64,1)`（吸附回弹）
  - 只动 `transform` 与 `opacity`（外加 SVG 的 `stroke-dashoffset`、`opacity`），不动 `width/height/top/left`（M4 对比条除外，用 SVG 矩形 `width` 补间，成本可接受）

## 5. 交互逻辑说明

### 5.1 模块 M2（发射基地条件）
- 用户操作：点行内唯一一枚「点击查看」/ 按 `空格`
- 触发逻辑：每行一个布尔状态 0→1，共 6 行；点按钮即把该行置为已查看，并展开该行的描述角度与有利条件；`空格` 展开第一条未查看的行
- 状态变化：行元素加 `is-open`；按钮收起（`display:none`），角度标签与有利条件错开一步淡入上浮（步间 200ms）
- 反馈方式：扫描光带扫过 + 行首序号牌点亮 + 底部进度「已全部查看 n / 6 条」
- 容错处理：已查看的行不再响应点击；6 行全部查看后进度为 6/6、「已完成查看」按钮由置灰转为可点；键盘监听只在 M2 进入视口（IntersectionObserver）时生效，避免影响其他屏

### 5.2 模块 M3（着陆场条件）
- 用户操作：点行内唯一一枚「点击查看」/ 按 `空格`
- 触发逻辑：与 M2 完全一致（同一个 `createConditionsTable` 工厂，参数不同）；每行一个布尔状态 0→1，共 4 行
- 状态变化：行元素加 `is-open`；按钮收起（`display:none`），角度标签与有利条件错开一步淡入上浮（步间 200ms）
- 反馈方式：扫描光带扫过 + 行首序号牌点亮 + 底部进度「已全部查看 n / 4 条」
- 容错处理：已查看的行不再响应点击；4 行全部查看后进度为 4/4、「已完成查看」按钮由置灰转为可点；键盘监听只在 M3 进入视口时生效

### 5.3 模块 M4（实景 + 精讲）
- 用户操作：点击发射场热点 / 着陆场热点；抽屉内点击角度标签；点击「看线速度」；点击「重播」
- 触发逻辑：
  - 热点 → `openDrawer(siteKey)`，抽屉从右侧滑入，默认只渲染**角度标签条**（发射场 6 / 着陆场 4）
  - 角度标签 → 该标签下展开三行（材料描述 / 有利条件 / 关键词高亮），可多开
  - 「看线速度」→ 打开演示浮层（overlay）：左栏 `createLatGlobe()` 建完整 Three.js 地球（不剖切、无辅助线），北半球与赤道三条纬线的扇形楔贴球面同步扫过 70° 展示跨度（南半球只标注纬度名，等时比弧长，真实 15° 已放大示意，扫掠循环见 05 文档 M4-子），纬度 / 弧长标签为 HTML 覆盖层投影定位；右栏五条对比条 `scaleX` 0→目标值（每条 300ms，错峰 100ms），数字用 `animate(proxy, { value })` + `onUpdate` 写文本
  - 「重播」可重播对比条与数字；浮层右上角可关闭，`Esc` / 点遮罩亦可关闭，关闭时必须 `globe.dispose()`
- 状态变化：`drawerSite`、`openAngles: Set<string>`、`demoOpen`
- 反馈方式：抽屉滑入 + 右侧对照表对比条伸长与数字滚动
- 容错处理：切换热点时抽屉内容整体替换（不叠加）；演示浮层打开时背景加半透明遮罩，点击遮罩关闭；**WebGL 不可用**时左栏替换为静态 SVG 示意（`fallbackSvg()`），**`prefers-reduced-motion`** 时三维只渲染静态一帧

### 5.4 模块 M5（四大基地配对）——本课技术重点
- 用户操作：从条件库拖拽条件卡到基地框；或（降级路径）先点条件卡选中、再点基地框投放
- 触发逻辑：
  - **自研拖拽**：`pointerdown` 记录起点 → 创建 ghost 元素（`position:fixed; pointer-events:none`）跟随指针 → `pointerup` 时用基地框 `getBoundingClientRect()` 做命中检测（点在 rect 内即为目标）
  - **重复使用**：拖拽源卡片**不移除、不置灰**（7 条条件可被多个基地引用）
  - **判定**：目标基地的 `conditionIds` 是否包含该条件 id
    - 命中且未挂载 → 吸附入框（250ms 回弹），框内列表追加一枚条件小标签，`mountedCount++`
    - 命中但已挂载 → 提示"该条件已挂载"
    - 未命中 → 卡片抖动 300ms 后飞回原位，框体闪红，toast 提示"这条条件与××基地的匹配关系不成立"
    - 释放点在所有框之外 → 卡片静默归位（不算错误，不提示）
  - **单基地完成**：`mounted.size === conditionIds.length` → 该基地 `is-done`（边框脉冲 800ms×2 + 勾号 + 引线变主色 + toast "酒泉基地条件挂载完成"）
  - **全课完成**：四基地均 `is-done` → 播放一次"发射成功"特效（overlay：轨道弧线掠过 + 尾焰粒子，≤2s，结束后移除 DOM 并显示可关闭的结算卡）
- 状态变化：`mountedByBase: Map<baseId, Set<condId>>`、`doneBases: Set<baseId>`
- 反馈方式：吸附/抖动/toast/框脉冲/结算卡（五级反馈必须齐备，这是薄弱学生注意力的抓手）
- 容错处理：
  - `pointercancel` / 指针移出窗口 → 归位，不判定
  - 拖拽中禁止文本选中（`user-select:none` + `touch-action:none`）
  - 提供「重置本模块」按钮（教师讲错可一键复原）
  - **数据驱动**：所有判定读 `lessonData.bases[].conditionIds`，教师调整归属只需改 `lessonData.ts` 一处
  - **图表生命周期**：重入 / 重置前必须 `chart.dispose()` 两个实例并断开 `ResizeObserver`，避免实例泄漏；`.m5__stage` 与各基地框尺寸变化时 `resize()` 后重排引线
  - **法规标注**：页脚固定「底图：DataV.GeoAtlas（示意，不作版图依据）」

### 5.5 模块 M6（随堂练习）
- 用户操作：点选项 → 点「查看答案」
- 触发逻辑：选中项加 `is-active`；揭示后正确项 `is-correct` + 勾号放大，错误项 `is-disabled`（降透明度）
- 状态变化：`selectedKey`、`revealed`
- 反馈方式：选中 150ms 高亮；答案区展开 300ms（高度过渡用 `grid-template-rows: 0fr→1fr` 技巧，避免 `height` 补间）
- 容错处理：允许改选直到揭示；揭示后可点「再练一次」重置

### 5.6 模块 M7（综合题分句与梳理）
- 用户操作：点「分句」→ 点句子卡 → 选描述角度 → 看规范表达
- 触发逻辑：
  - 分句：把 `lessonData.practice.material` 按句切分（预切分写在数据里，**不用运行时正则**，避免中文标点切分错误）→ 为每句创建 `.sentence-card` → 执行 **FLIP**：
    1. 先记录每张卡在原文中的 `getBoundingClientRect()`
    2. 把卡片移入左栏（改变 DOM 顺序/父节点），记录新 rect
    3. 用 `transform: translate(dx,dy)` 把卡"拉回"原位（invert）
    4. GSAP 补间到 `translate(0,0)`（play），错峰 60ms，单张 450ms
  - 点句子卡：该句填入右栏表格下一空行的「材料描述」列
  - 选角度：下拉/标签组选择 → 该行展开「精简语句」与「有利/不利」标记
  - 全部行完成后（或点「揭示参考」按钮）→ 显示「规范表达」列
- 状态变化：`split: boolean`、`rows: PracticeRow[]`、`currentRowIndex`
- 反馈方式：卡片飞行动画 + 表格行逐行高亮 + 底部作答要求常驻
- 容错处理：
  - 已填入表格的句子卡加 `is-used`（降低透明度但仍可点击复看）
  - 判分不做自动对错（本环节是"教师当场抓术语问题"，自动判分反而削弱讨论）——**只做"已选择角度"的记录，不判对错**
  - `prefers-reduced-motion` 或动画异常时降级为"直接布局切换 + 淡入"，必须有 `try/catch` 兜底

## 6. 数据结构建议（`src/data/lessonData.ts` + `src/types.ts`）
```ts
// 发射基地 / 着陆场选址条件（表 1、表 2 共用结构）
export interface SiteCondition {
  id: string
  material: string        // 材料描述（原文）
  angle: string           // 描述角度：气候 / 海陆 / 安全 / 地形 / 纬度 / 交通 / 人口 / 地表状况
  benefit: string         // 有利条件
  keywords: string[]      // 材料中需高亮的词
  icon?: string           // 内联 SVG symbol id（M4 速览卡 / 后续扩展备用）
}

export type BaseSlot = 'tl' | 'tr' | 'bl' | 'br'

export interface LaunchBase {
  id: 'jiuquan' | 'taiyuan' | 'xichang' | 'wenchang'
  name: string
  location: string        // 所在位置描述（省区/方位）
  lon: number             // 经度（ECharts geo 定点用）
  lat: number             // 纬度（ECharts geo 定点用）
  slot: BaseSlot          // 基地框在四角布局中的落位
  conditionIds: string[]  // 归属映射（2026-09-19 教师确认），判定唯一真源
}

export interface BaseTaskText { title: string; subtitle: string }  // M5 标题/副标题真源

export interface ConditionItem { id: string; index: string; text: string } // ①~⑦

export interface QuizQuestion {
  stem: string
  highlight: string[]     // 题干需高亮的句子
  options: { key: string; text: string }[]
  answerKey: string
  analysis: string
}

export interface PracticeRow {
  sentenceId: string
  angle?: string
  brief?: string
  polarity?: 'fav' | 'unfav'
  standard?: string
}

export interface LessonData {
  title: string
  conditions: { launch: SiteCondition[]; landing: SiteCondition[] }
  bases: LaunchBase[]
  conditionPool: ConditionItem[]
  quiz: QuizQuestion
  practice: {
    material: string
    sentences: { id: string; text: string }[]
    requirement: string
    answer: { fav: string[]; unfav: string[] }
  }
  latitudeDemo: { baseId: string; name: string; lat: number; speed: number }[]
}
```
- 全部内容（含 7 条条件文案、综合题材料与参考答案）**只在本文件出现一次**，各模块通过 `getLessonData()` 读取，禁止在模块内复制文案。

## 7. 风险与降级方案
- 高风险点：
  1. **中国地图的政治合规风险**（国界线/南海诸岛绘制不当会出教学事故）→ 2026-09-19 经教师确认：改用 DataV.GeoAtlas 数据（含南海诸岛附图与南海断续线）+ ECharts 离线渲染，下载精简后内联为 `src/data/chinaGeo.ts` 并登记 `docs/06_资源引用.md` 第 10/11 项；页面固定标注"底图：DataV.GeoAtlas（示意，不作版图依据）"。**禁止在模块内自定义/手绘任何国界与岛礁几何**，全部来自该数据文件
  2. **四大基地与 7 条条件的归属映射**（见 01 文档 §4.3）→ **已确认（2026-09-19，教师口径）**：酒泉 ①②、太原 ①④⑥、西昌 ③④⑤、文昌 ③⑥⑦；数据集中在 `lessonData.ts`，一处可改
  3. **拖拽在教室设备的兼容**（触控一体机 / 投屏笔 / 老浏览器）→ Pointer Events + 点击投放降级路径 + 「重置本模块」
  4. **FLIP 分句动画在低配教室电脑掉帧** → 限制卡片数（≤8 张）、只动 `transform`、提供降级与 `prefers-reduced-motion`
  5. **字体子集缺字**（"着陆场""燃料""文昌"等新字可能不在 `geo01` 子集内）→ 复用 `scripts/subset-fonts.mjs` 按**本课全部文案**重新生成子集，或直接内联一套覆盖本课文案的子集；生成后必须目视核对无"豆腐块"
  6. **一屏放不下**（1024×768 投影）→ M2 只有材料描述常显、结论按需展开，信息量已受控；矮屏下收紧行距与间距（字号不缩），必要时再加 `transform: scale()` 兜底，禁止出现必须滚动才能看完的教学内容
