# 资源引用登记表（本课指定资源引用页面）

本页是 `geo-sp01-space-launch` 一课的**项目指定资源引用页面**：页面中使用的所有**外部来源资源**（图片、视频、音频、字体等）的版权信息与来源链接，统一在此登记，保持引用格式统一、可追溯。本地原创/示意占位资源无需登记。

## 登记规则

1. 每新增一个外部来源资源，必须在本登记表追加一行，不得只改代码不登记。
2. 引用格式统一为：`资源用途 | 本地文件 | 作者 / 版权方 | 许可 | 来源链接 | 登记日期`。
3. 只登记"外部来源"资源；从公有领域 / CC 等许可获取的资源，须写明许可类型。
4. 若来源链接失效（如原站关停、改版迁移），须更新为官方迁移后的可访问链接，并在备注中注明迁移情况。
5. 禁止在课内代码/HTML 中直接引用远程 URL，外部资源须先下载到本课 `assets/`（或 `public/`）再引用。

- 第 13、14 项发射特效视频由课程教师用 AI 生成（原始文件 `assets/视频.mp4`：H.264 / 1280×720 / 24fps / 4.1s，含一条无用 AAC 音轨）。处理流程：先用 ffmpeg 无损去音轨（`-c:v copy -an`）并规范为 ASCII 文件名 `launch.mp4`；再离线转码出**带 alpha 通道**的 `launch.webm`——命令为 `ffmpeg -i launch.mp4 -vf "lumakey=threshold=0.16:softness=0.26,format=yuva420p" -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 30 -auto-alt-ref 0 -an launch.webm`（按亮度柔性抠除纯黑底，同时压掉 AI 素材自带的暗色光晕；已验证 `alpha_mode=1`，可解码出 rgba）。两个文件均按项目约定放在 `public/`，构建时原样复制到 `dist/` 根目录、不内联；**WebM 在浏览器中即为"透明 PNG"式叠加**，无需任何混合模式（页面 source 顺序见第 16 项备注）。**生成工具与服务条款待补充**。
- **第 16 项（Safari 用 HEVC + alpha）需在 Mac 上生成**——Windows 侧的 ffmpeg 不具备此能力（`hevc_videotoolbox` 是 Apple 独有框架，`libx265` / NVENC / QSV 均不支持 alpha；APNG / 动图 WebP 作为替代实测达 17~35MB，不可用）。步骤：
  1. 把本课 `public/launch.mp4`（原始黑底素材，**不要**用已抠像的 webm，避免二次压缩）拷到 Mac。
  2. 命令行转码（需 macOS 10.15+ 与较新的 ffmpeg；`alpha_quality` 为 VideoToolbox 的 alpha 层质量）：
     ```bash
     ffmpeg -i launch.mp4 -vf "lumakey=threshold=0.16:softness=0.26,format=yuva420p" \
       -c:v hevc_videotoolbox -alpha_quality 0.75 -allow_sw 1 -tag:v hvc1 -an launch-hevc.mov
     ```
     GUI 备选（社区验证过的路径）：先用剪辑软件导出 ProRes 4444 且**勾选 alpha**，再用 Shutter Encoder 选 H.265(.mp4) → 硬件加速 `OSX VideoToolbox` → 勾选 **Enable alpha channel**。
  3. 校验 alpha 已写入：`ffprobe -select_streams v -show_entries stream_tags=alpha_mode -of default=noprint_wrappers=1 launch-hevc.mov`（期望 `alpha_mode=1`）。
  4. 放到本课 `public/launch-hevc.mov`，然后重跑构建。
  - 页面 source 顺序为 **`.mov`(video/quicktime) → `.webm` → `.mp4`**：Safari 取第一个；Chrome / Edge / Firefox 因声明为 `video/quicktime` 而跳过它（**不能**改成 `video/mp4; codecs="hvc1"`，否则支持 HEVC 解码的 Chrome 会误选并丢失 alpha，退化成黑底）。文件缺失时浏览器自动顺延到 webm，不影响其他浏览器。
  - 已知风险：iOS 上 HEVC-alpha 存在渲染缺陷（透明区被当作叠加层、亮度异常），Apple 开发者论坛有多例报告，需在真机验证；如 iOS 表现不佳，可让 iOS 走 SVG 降级动画。
- 第 15 项为 M4-子 线速度演示中三维地球的球面贴图：2026-09-19 从 NASA Visible Earth 页面（Blue Marble: Land Surface, Shallow Water, and Shaded Topography）下载 `land_shallow_topo_2048.jpg`（2048×1024，238676 字节），规范为 ASCII 文件名 `earth-blue-marble.jpg` 后放入本课 `assets/textures/`。NASA 素材属**公有领域**，可自由用于教育用途（建议注明出处，页面已登记本表）。构建时经 `vite.config.ts` 的 `assetsInlineLimit` 规则**强制 base64 内联**进单文件（双击 `dist/index.html` 即可离线加载，且规避 `file://` 下的贴图跨域限制），因此**不产生独立的外链文件**；运行时不联网。
