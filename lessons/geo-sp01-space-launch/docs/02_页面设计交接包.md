# 页面设计交接包

> 风格锚点：HUD / Sci-Fi FUI（太空任务控制界面），但把"可读性"置于"炫技"之上——这是公开课投屏，不是设计作品集。

## 1. 页面整体定位
- 页面类型：**混合型**——卡片分区（M2/M3）+ 地图主导（M4/M5）+ 图解探索（M7）
- 风格关键词：深空底色 / HUD 仪表面板 / 轨道弧线 / 冷色高光 / 数据等宽字 / 克制
- 目标用户：高三一轮复习学生（基础较差、兴趣不浓厚）+ 授课教师（投屏操作）
- 使用场景：公开课课堂讲授为主，导学案前置自学；课后学生可自主回看；**不要求手机适配**
- 视觉策略摘要：
  1. **一屏一事**：每个模块只承担一个任务，信息一次只展开一条，避免"电子教材"式堆砌。
  2. **深色底盘 + 高对比正文**：背景极深，正文近白，卡片靠 1px 冷色描边和微弱辉光分层，**不用大面积高饱和渐变**（投屏易发灰）。
  3. **科幻语汇只在"装饰层"**：角标、扫描线、轨道弧线、网格属于装饰，正文与表格保持朴素清晰。
  4. **每个环节一套明确的动效隐喻**：条件表（任务一 / 任务二）用「雷达扫描 + 点击查看」，其余用 轨道加速 / 挂载对接 / 分离回收，用"航天动作"对应操作语义。

## 3. 视觉系统
### 色彩
- 主色：`--c-primary: #35C6F4`（HUD 冰蓝，用于强调、连线、进度）
- 辅助色：`--c-accent-2: #7B61FF`（轨道紫，用于次要强调与渐变端点）
- 强调色：`--c-accent-warm: #FFB020`（警示/重点标注，如"纬度""分句"关键词高亮）
- 背景色：`--c-bg: #060A14`（深空）；面板 `--c-panel: #0D1524`；面板描边 `--c-line: rgba(53,198,244,.28)`
- 正文色：`--c-text: #E8EFF8`（对比度 ≈ 14:1，远超 4.5:1）；次要文字 `--c-text-dim: #93A4BC`
- 状态色：正确 `--c-ok: #2ED47A`；错误 `--c-err: #FF5C6C`；提示 `--c-info: #35C6F4`
- 投影安全阈值：正文与背景对比度 **≥ 7:1**；表格斑马纹用 `rgba(255,255,255,.03)`，**不得**用低对比灰字（`#93A4BC` 仅用于注释，不承载考点信息）
- 备选（P1）：顶部提供「投影增强」开关，一键切到浅底高对比配色（教室投影偏亮/偏灰时的保险）

### 排版
- 字体：思源黑体（Noto Sans SC）子集，400 / 700；关键字与数据用等宽感数字（可用 `font-variant-numeric: tabular-nums`）
  - 字体文件已在 `geo01` 课内存在，本课**复制到本课 `assets/fonts/`** 使用（并登记 `06_资源引用.md`），保持单课自包含
- 页面主标题：44–56px / 700
- 二级标题（模块标题）：30–34px / 700，左侧带 4px 主色竖条
- 正文：22px / 400，行高 1.7
- 表格文字：20–22px（**投屏最小字号 20px，任何内容不得低于此值**）
- 注释 / 提示：18px，颜色 `--c-text-dim`
- 数据/数字（线速度、纬度）：28px / 700 + 主色

### 组件风格
- 卡片：`--c-panel` 底 + 1px `--c-line` 描边 + 四角 8px HUD 角标（用 `::before/::after` 或 SVG），圆角 12px，无重投影，仅 `0 0 0 1px` 内发光
- 按钮：胶囊形；主按钮主色描边 + hover 时背景 `rgba(53,198,244,.12)`；**统一 200ms 过渡**；focus 有可见外框（键盘/投屏遥控操作可用）
- 标签（角度标签）：小号胶囊，冰蓝描边；点击后填充主色 12% 并变亮
- 提示框：左上角带小三角/引线，用于"教师提示"（如"注意：这里的气候≠晴天多"）
- 反馈框：正确 → 绿色描边 + 卡片右移 4px + 勾号图标；错误 → 红色描边 + 横向抖动 300ms + 提示文案
- 图表/地图容器：统一 16:9 或 4:3 面板，内嵌 SVG，无外部图片（离线约束）

## 4. 模块详细说明

### 模块 M0 任务路线导航
- 教学目的：公开课节奏控制，师生都能看到进度
- 页面位置：顶部固定，高 56px
- 内部结构：左「航天发射相关问题 · 高三一轮复习」；中 4 个任务点（选址条件 / 四大基地 / 随堂练习 / 综合题训练）；右「重置本页」按钮
- 首先看到什么：当前任务点高亮 + 进度线
- 强调什么：进度，不抢内容
- 交互入口位置：任务点可点击跳转（教师控场用）
- 反馈区域位置：无
- 动效建议：进度点切换时 300ms 填充动画，不做位移动画
- 投屏注意：固定在顶部不遮内容；背景用半透明 + 毛玻璃兜底，深底上仍清晰

### 模块 M1 情境导入
- 教学目的：3 秒建立情境，抛出"为什么建在这里、为什么落在这里"
- 页面位置：全屏首屏
- 内部结构：深空网格背景 → 自绘火箭轨迹弧线（SVG path 描边动画）→ 主标题 → 一条悬念提问 → 「开始本课」按钮 → 四项任务清单（淡入）
- 首先看到什么：轨迹弧线先画出，再出标题
- 强调什么：悬念提问，不强调装饰
- 交互入口位置：屏幕中下部按钮
- 反馈区域位置：点击后本模块整体上滑退场，进入 M2
- 动效建议：轨迹描边 1200ms（ease-out）；标题 500ms 上浮淡入；总时长 ≤ 2.5s，且**可点击跳过**
- 投屏注意：不用视频、不用大图，避免加载抖动；文字在投影下必须锐利

### 模块 M2 发射基地选址条件（发射视角 · 点击查看）
- 教学目的：由学生说出"描述角度"，逐条核对
- 页面位置：第二屏，模块标题"任务二 · 发射基地建在哪"，右上角条件总数徽标，标题下为一句导语
- 内部结构：
  - 表头四列：**序号 | 材料描述 | 描述角度 | 有利条件**
  - **材料描述默认全部呈现**（关键词高亮），学生先读材料、想角度
  - 「描述角度」「有利条件」两栏之间**只有一枚「点击查看」按钮**（6 行尺寸完全一致，居中压在两栏分界线上）；点它即把该行的角度标签与有利条件**一起展开**，行首序号牌同步点亮
  - 底部固定：左侧操作提示，右侧进度「已全部查看 `n / 6` 条」+「已完成查看」按钮（未看全时置灰）
- 首先看到什么：全部 6 条材料 + 6 枚「点击查看」按钮——先让学生带着问题读材料
- 强调什么：材料中的关键词（"降水少""纬度低""交通设施完善"）与角度标签、有利条件的对应关系
- 交互入口位置：每行两栏中间的「点击查看」按钮（240×58px、眼睛图标 30px，便于教室远距离点击）；`空格键` 可依次展开下一条
- 反馈区域位置：按钮原位（按钮收起、结论原地呈现）+ 底部进度
- 动效建议：雷达扫描隐喻——一行展开时，从行首扫过一道 600ms 的主色光带；角度与结论错开一步淡入上浮。整体节奏 400–600ms，不拖慢课堂
- 投屏注意：材料描述列 ≥ 50%；正文字号按视口放大（≥ 24px），保证教室后排可读；6 行全部展开后仍在**一屏内**

### 模块 M3 着陆场选址条件（任务二 · 与 M2 同一套条件表）
- 教学目的：掌握 4 个角度，并与 M2 形成"需求差异"的反差（反差由**内容**承担，不再由形态承担）
- 页面位置：第三屏，模块标题"任务二 · 返回舱落在哪"，右上角徽标"航天器着陆场的选址条件 · 共 4 条"
- 内部结构（复用 M2 的条件表组件，仅标题 / 徽标 / 导语 / 条数不同）：
  - 表头四列：**序号 | 材料描述 | 描述角度 | 有利条件**
  - **材料描述默认全部呈现**（关键词高亮）
  - 描述角度与有利条件两栏之间一枚「点击查看」，点开即同时呈现该行的角度标签与有利条件，行首序号牌点亮
  - 底部固定：左侧操作提示，右侧进度「已全部查看 `n / 4` 条」+「已完成查看」按钮
- 首先看到什么：4 条完整的材料描述——学生先读材料、再判断"落点选址关心什么"
- 强调什么：**着陆场关心的是"安全疏散 + 能见度 + 搜救视野 + 落地环境"**，与发射场关心"省燃料、便于运输"不同
- 交互入口位置：每行两栏中间的「点击查看」按钮（与 M2 同尺寸）；`空格键` 可依次展开下一条
- 反馈区域位置：按钮原位（按钮收起、结论原地呈现）+ 底部进度
- 动效建议：与 M2 同一套——行首扫描光带 600ms + 角度与结论错开一步淡入上浮
- 投屏注意：与 M2 相同字号令牌（正文 ≥ 24px），4 行全部展开后仍在一屏内

### 模块 M4 实景选址对照 + 纬度精讲
- 教学目的：一页对照两类选址；重点突破纬度线速度难点
- 页面位置：第四屏
- 内部结构：
  - 主画面：自绘风格化实景地形图（SVG，海岸 + 平原 + 山地 + 植被纹理），**左侧热点＝发射场**，**右侧热点＝着陆场**
  - 点击热点 → 右侧**抽屉面板**滑出（不遮地图，便于教师指点位置）
  - 抽屉内呈现方式（回答"描述角度怎么呈现"这一疑问）：
    - 默认**只列角度标签条**（发射场 6 条 / 着陆场 4 条），一屏全见，学生可自主点开自己不明白的那个
    - 点击某角度 → 该标签下方展开三行：材料描述 / 有利条件 / 关键词高亮
    - 「纬度」标签额外带一个「看线速度」按钮
  - 线速度演示层（本课技术难点，见 03 文档；2026-09-19 教师定稿：完整地球 + 仅楔形动画）：
    - 结构：标题行「地球自转的线速度」+ 右侧「重播」按钮与关闭钮 → 副标题「纬度**越低**，线速度**越大**，发射更省燃料」（关键词着色）→ 左栏 3D 地球 → 右栏 纬线对照表 → 底部结论卡
    - 左：**完整三维地球**（Three.js + **NASA Blue Marble 公有领域影像贴图** `assets/textures/earth-blue-marble.jpg`，球面上叠加 30° 极淡经纬网与 5 条教学纬线；**不剖切、无纬线圆环 / 地轴等辅助线**——立体感靠影像本身 + 明暗光照 + 大气光晕而非线条）；标注北极 / 南极（贴球体视觉上下边缘）；**北半球两条纬线与赤道（60°N / 30°N / 0°）各带一个从纬线圆心扫过的扇形楔**（30°S / 60°S 只标注纬度名、不带动画——教师要求；**展示跨度 70° 为放大示意**，真实 1 小时 = 15°；扇形贴球面渲染、在地球右侧），扫描时三楔同步（同一小时转角相同），外缘弧长标注 837 / 1447 / 1670 km——纬度越低弧越长，赤道用主色强调；五个纬度名在球体左缘外一列对齐各纬线
    - 右：5 行纬线对照表（纬线 / 对比条 / 线速度），60°N 233、30°N 401、0°（赤道）465、30°S 401、60°S 233 m/s
    - 底部一行结论卡（火箭图标）：**在赤道发射，可获得最大初始速度加成 / 最高可达约 465 m/s**
    - 打开即自动演示：对比条按比例伸长 + 数字滚动；「重播」在标题行右侧
- 首先看到什么：两个脉冲热点，学生先判断"这两个地方分别是什么"
- 强调什么：纬度与线速度的对应关系（赤道 465 m/s 与 60°N 233 m/s 相差一倍），以及"同一角速度、半径不同"这一几何原因
- 交互入口位置：热点（大热区 ≥ 64px，便于触控一体机）；抽屉内角度标签；「看线速度」按钮
- 反馈区域位置：抽屉内 + 演示层右侧对照表与结论卡
- 动效建议：热点常驻 2s 脉冲（`prefers-reduced-motion` 下停用）；抽屉滑入 350ms；演示层打开后对比条错峰伸长 + 数字滚动；3D 地球本体静止，运动语义 = 扇形楔每循环扫过 15°（`prefers-reduced-motion` 下呈现静态终态帧）
- 投屏注意：线速度数值字号 ≥ 32px；五条纬线的名称必须与数值同屏可见；3D 地球关闭浮层时必须释放 WebGL 上下文

### 模块 M5 任务三 · 四大基地选址条件（挂载对接）
- 教学目的：建立四大基地空间位置认知，匹配 7 条有利条件
- 页面位置：第五屏
- 标题与副标题（真源在 `lessonData.baseTask`）：
  - 标题「**任务三 · 四大基地选址条件**」（四屏标题统一用间隔号，与其它三屏一致）
  - 副标题「拖动下方有利条件胶囊，把它放进对应的发射基地框」
- 内部结构（对齐设计稿：**地图居中、四框分布四角、底部条件胶囊池**）：
  - 中部：**中国地图底图**（ECharts 离线渲染，数据源 DataV.GeoAtlas，见 06 资源引用；省级边界 + 主体版图偏居中），四点标出基地位置：酒泉（西北内陆）、太原（华北）、西昌（西南）、文昌（海南低纬沿海）
  - **南海诸岛附图**：地图框右下/左下角小型附图框，含岛礁与南海断续线，框下标注「南海诸岛」
  - **四角矩形框**：左上＝酒泉、右上＝太原、左下＝西昌、右下＝文昌；框内显示：基地名 + 所在位置（省区/方位）+ 已挂载条件胶囊列表 + 右上角计数「已挂载 / 应有」
  - **框体尺寸恒定**：四个框在进入本屏时就按"自身条件全部挂载后"的尺寸占好高度，投放过程中**不随胶囊增减变大变小**（避免框体跳动、引线抖动）
  - **折线引线**：由地图上的基地点位连到对应框的最近边，虚线默认、基地完成转主色实线
  - 底部：「有利条件」7 张条件胶囊（①②…⑦），横向排布于 HUD 面板内
  - 页脚：操作提示 + 地图来源标注「底图：DataV.GeoAtlas（示意，不作版图依据）」+「重置本模块」
  - 拖拽规则：**条件胶囊可重复使用**（不消耗），支持反复拖拽到任意基地框；拖入正确 → 吸附入框、胶囊上计数 +1、框内计数 +1；拖入错误 → 卡片抖动 + 框体红描边 + 提示"这条条件与××基地的匹配关系不成立"
  - 框内胶囊**可点击取回**（课堂纠错用，不计错、不提示错误）
  - 基地完成判定：该基地应含条件全部挂载后 → 框体边框脉冲发光 + 出现勾号 + 引线变主色
  - 全部完成后 → 顶部出现一次"发射成功"轻特效（轨道弧线掠过 + 尾焰粒子，≤ 2s，可点击关闭）
- 首先看到什么：中国地图 + 四个空框——先让教师问"文昌在哪？它最特别的是什么？"
- 强调什么：**条件与基地的一一对应关系**，尤其是"⑦临海"只属于文昌、"③纬度低"只属于文昌
- 交互入口位置：底部条件胶囊（可拖可点：拖拽为主，**点击投放为降级路径**——先点胶囊再点基地框）；框内胶囊可点击取回
- 反馈区域位置：基地框内部 + 胶囊计数 + 页脚上方提示条
- 动效建议：拖拽时胶囊轻微上浮 + 阴影；吸附 250ms 弹性；错误 300ms 抖动；完成脉冲 800ms ×2
- 视觉风格：沿用本课深色科技风——底图陆地填充取 `--c-panel-2`（低饱和深蓝），边界线取 `--c-line`，基地点位用暖金 `--c-accent-warm`，基地框默认虚线边框、命中时主色高亮、完成转绿+勾号
- 投屏注意：地图与四个框必须**同屏可见**（16:9 投屏下不滚动）；框内文字 ≥ 20px；引线不要与地图要素重叠

### 模块 M6 随堂练习
- 教学目的：即时检测
- 页面位置：第六屏
- 内部结构：题干卡（含"长征 5 号天津制造 → 海运至文昌"关键句高亮）→ 四个选项按钮 → 「查看答案」按钮 → 答案区展开（正确答案 + 一句解析："体积质量大 → 需要海运 → 对应交通/运输能力"）
- 首先看到什么：题干与四个选项
- 强调什么：题干中"天津制造""体积大质量大"与答案 A 的因果
- 交互入口位置：选项按钮 + 揭示按钮
- 反馈区域位置：选项下方答案条
- 动效建议：选中选项 150ms 高亮；揭示时正确项打勾放大，错误项降透明度
- 投屏注意：选项横排两行，字号 ≥ 24px

### 模块 M7 综合题规范训练（分离回收）
- 教学目的：把"读材料 → 分句 → 定角度 → 转术语 → 分点写"变成看得见的动作
- 页面位置：第七屏
- 内部结构：
  - 左栏：材料原文（按段落排版）
  - 顶部/左侧按钮：「分句」——点击后材料按句切分，每句变成一张**圆角矩形卡片**，从原文位置"炸开"飞向**左栏并竖排堆叠**（卡片内为该句原文，关键词高亮）
  - 右栏：答题表格 `材料描述 | 描述角度 | 精简语句 | 有利/不利 | 规范表达`
  - 操作流：点击左侧句子卡 → 该句填入表格"材料描述"列 → 出现角度下拉（气候 / 地形 / 交通 / 纬度 / 人口 / 安全 / 海陆 / 地表状况…）→ 选角度后展开"精简语句 + 有利/不利" → 全部行完成后揭示"规范表达"参考列
  - 底部：作答要求（用自己的语言；至少 1 条有利 + 1 条不利）
- 首先看到什么：材料原文 + 一个醒目的「分句」按钮（先让学生自己读一遍）
- 强调什么：**每一句都对应一个角度**；分点写、用术语；不利因素不能漏
- 交互入口位置：「分句」按钮；句子卡片；表格内下拉/点击格
- 反馈区域位置：右栏表格 + 底部规范表达区
- 动效建议：分句卡片用 FLIP 思路（先记录原位 → 再绝对定位飞向左栏），错峰 60ms，单张 450ms，缓动 `cubic-bezier(.2,.8,.2,1)`；禁用时会退化为"直接切换布局 + 淡入"
- 投屏注意：分句后左栏卡片最多 8 张需一屏容纳（自动两列或缩小行高）；表格可横向滚动但**关键列（描述角度/规范表达）常驻可见**

- 页面位置：第八屏

## 5. 设计约束
- 必须保留的设计点：
  1. 任务一 / 任务二两张条件表使用**同一套条件表组件**（材料描述常显 + 点「点击查看」展开整条，2026-09-19 教师确认改为同一种呈现方式）：组件参数化，只有标题、徽标、导语、条数不同；两表的差异由条件内容本身承担，不再由形态承担
  2. M4 的"点击热点弹出条件"与"纬度线速度演示"
  3. M5 的"条件卡可重复拖拽 + 对错即时判定 + 单个基地完成特效 + 整体完成特效"
  4. M7 的"材料分句炸开 + 左侧堆叠 + 右侧表格梳理"
  5. 全站投屏可读：正文 ≥ 20px，关键数字 ≥ 28px
- 可降级的设计点：
  1. M4 线速度演示：从"逐条伸长动画"降级为"静态对比条 + 数值"（教学结论不变）
  2. M7 分句动画：从 FLIP 飞行降级为布局切换 + 淡入
  3. M5 中国地图：若 ECharts 或地图数据加载异常 → 隐藏地图层，四角基地框与底部条件胶囊仍可正常拖拽配对（判定逻辑不依赖地图）
  4. M8 打印导出：直接删除
- 应避免的视觉问题：
  1. 大面积高饱和渐变 / 霓虹光晕铺满正文区（投屏发灰、刺眼）
  2. 同一套动效连续用四次（课堂节奏雷同）
  3. 深色底 + 低对比灰字（考点信息必须高对比）
  4. 装饰元素（网格、扫描线）压过文字层级
  5. 单屏滚动超长（投屏翻页笔无法滚动，**每屏内容控制在 1 屏内**）
- 对技术实现的重点要求：除 **M4-子 三维地球的球面影像**（NASA Blue Marble，见下）外，全部图形（地图、实景图、地球自转示意）用 **SVG 自绘**，不引入外部图片库；动效统一走一套时长/缓动变量；提供 `prefers-reduced-motion` 与「投影增强」两个开关

## 6. 资源建议
- 图片/插图：**建议零位图**——所有插图（火箭轨迹、实景地形、地球自转示意、中国轮廓）用 SVG 矢量自绘，天然离线、投屏锐利、体积小、易调色
