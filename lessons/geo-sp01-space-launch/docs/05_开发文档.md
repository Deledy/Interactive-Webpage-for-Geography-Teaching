**综合题（`practice`）**
- `material`：导学案原文（见 `docs/导学案知识点内容.docx` 第二题，逐字录入，不得改写）
- `sentences`（**预切分为 7 句，禁止运行时正则切分**）：
  1. `p1` 某航天发射场建于南美洲北部沿海地区，地理位置约为北纬5°附近。 → 角度：纬度 → fav
  2. `p2` 该地东临大西洋，发射方向可避开人口密集地区，并可使火箭飞行初期经过海域上空。 → 角度：海陆／安全 → fav
  3. `p3` 发射场所在区域为面积较大的沿海低地，地面起伏较小，周边森林广布，人口和城镇分布较少。 → 角度：地形（+人口）→ fav
  4. `p4` 该地区河流众多，部分河流下游河段宽阔。 → 角度：交通 → fav
  5. `p5` 由于大型火箭及配套设备体积大、质量大，建设和运行过程中需要依靠海运及河运运输部分物资。 → 角度：交通 → fav
  6. `p6` 该地属于全年高温多雨的热带气候，年降水量较大，空气湿度较高，云量较多，雷雨天气出现较频繁； → 角度：气候 → unfav
  7. `p7` 但在部分月份降水相对较少，适宜选择天气状况较好的时段进行发射。 → 角度：气候 → fav（有限制的有利）
- `requirement`：`结合材料，分析该地建设航天发射基地的有利条件和不利因素。（要求：用自己的语言作答；至少写出1条有利条件、1条不利因素）`
- `answer.fav`：① 纬度低（约 5°N），自转线速度大，可节省燃料和成本；② 东临大西洋，发射方向经海域上空且人口城镇少，人烟稀少，安全性强；③ 沿海低地地形平坦开阔，便于跟踪观测与设备布置；④ 河运海运便利，利于大型设备运输。
- `answer.unfav`：① 全年高温多雨、空气湿度大、云量多，不利于发射与跟踪观测；② 雷雨天气频繁，可发射窗口受限（需择期发射）；③ 森林广布、气候湿热，设备维护与运输条件较差。

### M4-子 纬度线速度演示（`latSpeedDemo` + `latGlobe`）
- **讲解逻辑**（2026-09-19 教师定稿：完整地球 + 仅楔形动画）：各地随地球自转**同一小时都转过相同角度** → 各纬线的圆周半径 `r = R·cosφ` 不同 → 转过的弧长（837 / 1447 / 1670 km）不同 → 线速度 `v = ω·r` 不同。演示主线是"等角（等时）比弧长"；**扇形展示跨度放大到 70°**（`WEDGE_A = 15°` 起、B 至 85°；真实 1 小时 = 15°，教师确认动画数据与展示数据可以不符，表达清楚即可）。
- **实现要点**：
  - 卡片结构（对齐设计稿，2026-09-19 教师反馈修订）：标题行「地球自转的线速度」+ 右侧操作区（「重播」胶囊按钮 + 关闭钮）+ 副标题（`highlight` 关键词着色）→ 左栏 3D 地球（无说明行、无页脚）→ 右栏 表头 / 5 行纬度对照（对比条 + 数值）/ 赤道结论卡。
  - **左栏三维模型 `latGlobe.ts`**（Three.js，根依赖已含）：
    - **完整地球**（不剖切、无内壳 / 剖面盘 / 纬线圆环 / 地轴虚线 / α 文字 / 地心标注——教师反馈"四面散射的线导致立体感不足"，全部删除）：`SphereGeometry(R, 64, 48)` + 程序化 `CanvasTexture` 地表贴图（海洋 + 示意陆地 + 经纬网）。立体感三要素：环境光 0.8 + 太阳方向光 1.8（明暗过渡）+ 背缘光 0.85（勾轮廓），自发光仅 `#0c2240`×0.55 垫底、粗糙度 0.6 出海面高光；舞台 `--sz-lat-stage: 500px`（矮屏 ≤780px 高时 460px）、取景半宽 `VIEW_HALF = 1.3`，球体直径约占舞台高度 77%。
    - **扇形楔（核心）**：**仅北半球两条纬线与赤道共 3 个扇形**（30°S / 60°S 只保留纬度名标注、不带动画——教师 2026-09-19 要求；`BufferGeometry` 三角扇，**必须设三角扇索引**，否则非索引渲染会把顶点错切成细长尖刺——已踩坑），顶点在**纬线圆心（地轴上）**，外缘沿纬线扫过 **70° 展示跨度**（`WEDGE_A = 15°` 起始，扇形在地球右侧）；材质**关闭深度测试**贴在完整球面上方渲染（扇形半径 0.995r 在球面内侧，否则被球体遮挡）；扫描动画"扫出 2.4s → 保持 3.0s → 收回 0.5s → 停顿 0.5s"循环，三条纬线**同步**扫过——即"角速度相同"；A 点（起始）与 B 点小球 + 方向箭头（随扫掠东移）同样贴面渲染。
    - **相机高位俯视** `(0, 2.55, 2.95)` lookAt `(0, 0.05, 0)`（俯角约 41°，`CAM_DIST = 3.9`）：扇形在水平面上，此前平视（俯角 17°）被透视压成细条——45° 跨度视觉上与 15° 无异（教师反馈"扇形范围依旧是之前的情况"的根因）；俯视让纬线平面正对视线，扇形展开度提升约 2.3 倍，五层扇形的半径差异也一目了然。
    - **标注**：HTML 覆盖层标签，`fit()` 中统一投影定位——极点标注水平对齐球心、垂直贴**球盘视觉边缘外 20px**（投影半径 `tan(asin(R/D))×焦距` 推算；锚在 `(0,±R)` 会投影进球盘内部——已踩坑）；五个纬度名**右对齐钳制到球盘左缘外 10px 一列**、对齐各纬线左端投影高度（教科书排布，不浮离球体）；各扇形外缘弧长 `arcKm` km（锚 `r×1.18`，随扫掠淡入，不压盖扇面、不溢出舞台右缘）。
    - 地球本体静止（运动语义 = 1 小时自转扫掠）。
  - 配色一律读 `tokens.css`：赤道 = `--c-primary`，中纬 / 高纬 = `--c-accent-2`（三档透明度），与右侧对比条 `data-band` 一一对应。
  - 右侧对比条 `scaleX` 由 0 → `speed / max(speed)` 补间，每条 300ms、错峰 100ms；数字用 `animate(proxy, …)` + `onUpdate` 写文本（tabular-nums）；数值字号 `--fs-lat-val`（36px）。

  - **基地点位**：`lessonData.bases[].lon/lat` 经 `scatter` 系列（`coordinateSystem: 'geo'`）落点（暖金 `--c-accent-warm` + 光晕），不做地图交互（`roam: false`、`silent`）
  - **四角基地框**：`.m5__stage` 为定位容器，`.m5__box` 按 `data-slot`（`tl`/`tr`/`bl`/`br`，来自 `lessonData.bases[].slot`）绝对定位到四角，地图居中（`.m5__board` 左右各留 25%）；框内显示「基地名 + 所在位置 + 已挂载条件胶囊列表 + 计数 n / 应有」
  - **框体尺寸预占**（`reserveBoxHeights()`）：初始化时用"该基地条件全部挂载后"的真实胶囊做一次隐藏测量（探针 `.m5__slots--probe`），把结果写为该框的 `min-height`，使四个框**在投放前就与投放后一样大**，投放过程中不放大、位置不跳动；测量时临时隐藏真实胶囊并加 `is-filled` 以屏蔽占位提示，量完即还原；舞台尺寸变化时重算（胶囊换行随框宽变化）
  - **SVG 折线引线**（`.m5__leaders`，`viewBox="0 0 100 100"` + `preserveAspectRatio="none"`）：端点 `from` 由 `chart.convertToPixel({ geoIndex: 0 }, [lon, lat])` 取地图像素坐标，再按舞台矩形折算为百分比；端点 `to` 取基地框矩形上离 `from` 最近的边界点；`d = M from L 中点 L to` 形成折线。默认虚线，基地完成转主色实线
  - **重排时机**：`ResizeObserver` 监听 `.m5__stage`（窗口缩放 / 全屏）→ 舞台尺寸变化时先 `reserveBoxHeights()` 重算预占高度，再 `relayout()`（先 `chart.resize()` 两个实例，再 `layoutLeaders()`）；`convertToPixel` 用 `try/catch` 兜底，取值异常时移除该条引线
  - **配色**：全部读 `tokens.css`（`cssVar()` 读计算值），陆地填充 `--c-panel-2`、边界 `--c-line`、点位 `--c-accent-warm`；canvas 不支持 `color-mix`，透明度由 `withAlpha()` 手动换算为 `rgba()`
  - **自研 Pointer Events 拖拽**：`pointerdown` → 创建 fixed 定位 ghost 跟随 → `pointerup` 用基地框 `getBoundingClientRect()` 命中检测；条件胶囊**不移除不消耗**，可重复拖向多个基地；移动距离 < 6px 视为点击（走降级路径）
  - 判定：目标 `conditionIds` 含该 id 且未挂载 → 吸附入框（250ms `--e-back`）+ 框内追加条件胶囊 + `mountedCount++` + 胶囊上计数更新；已挂载 → toast"这条条件已挂载到该基地"；不含该 id → 胶囊抖动 300ms + 框体闪红 + toast"这条条件与××基地的匹配关系不成立"；释放在所有框外 → 静默归位不提示

  - **单基地完成**：`mounted.size === conditionIds.length` → 框体 `is-done`（边框脉冲 800ms×2 + 勾号 + 引线变主色）+ toast"××基地条件挂载完成"

## 5. 通用实现规范
1. **文案零复制**：所有教学内容只存在于 `lessonData.ts`；模块中不得出现写死的条件文案、题干、材料。
2. **状态类统一**：`is-active` / `is-done` / `is-correct` / `is-wrong` / `is-revealed` / `is-used` / `is-disabled`；反馈类 `feedback--ok|err|info`。
3. **动效令牌统一**：时长与缓动一律引用 `tokens.css` 中的 `--t-*` / `--e-*`，不得在模块内写魔法数字。
4. **只动 `transform` 与 `opacity`**（例外：M4 对比条 SVG 矩形 `width`）。
5. **一屏一个 `<section class="screen">`**，每屏内容必须在一屏内呈现（1024×768 兜底，必要时整体 `transform: scale()`，禁止缩小字号）。
6. **键盘支持**：`空格`（M2/M3 展开下一条未查看行）、`Esc`（关闭抽屉/浮层）、`Tab` 焦点可见（`.focus-visible` 外框）。
7. **无网络**：不得出现任何 `http(s)://` 字符串（`npm run check` 会告警）；不得引用 CDN 字体/图标。
8. **重置能力**：每个含状态的模块导出 `init()` 与 `reset()`，`main.ts` 统一注册到 M0 的重置入口。
