# 页面设计交接包

课题：第一章 宇宙中的地球 · 第一节 地球的宇宙环境

## 1. 页面整体定位
- 页面类型：混合型（线性讲授型为主轴，穿插卡片分区、图解探索与互动练习）
- 风格关键词：宇宙感、深邃、星空、发光、科技感、沉浸
- 目标用户：高一学生（课堂听讲与课后自学）、地理教师（投屏讲授、公开课展示）
- 使用场景：课堂讲授（投屏，远距离可读）/ 学生自学 / 复习巩固 / 公开课展示
- 视觉策略摘要：以深空蓝紫黑为底色承载"宇宙感"，内容放在半透明玻璃拟态卡片中形成层次；星点与发光效果只作氛围，不干扰文字；通过"逐级放大"动效表达空间尺度；每个模块右上角设置统一的"拓展"入口，满足学有余力学生的自主学习需求。

## 3. 视觉系统
### 色彩
- 主色：深空蓝 #0B1026、星云紫 #1A1040（页面底色与主容器）
- 辅助色：深色玻璃面 rgba(255,255,255,0.06)、描边 rgba(255,255,255,0.14)
- 强调色：恒星金 #FFD54F（标题、重点、选中态）、星云青 #4FC3F7（次级强调、链接、行星动效）
- 背景色：径向渐变（#0B1026 → #1A1040 → #0A0A18），叠加静态星点层
- 状态色：正确 #66BB6A、错误 #EF5350、提示 #FFB74D

### 排版
- 页面主标题：48px+，加粗，字距略宽，恒星金
- 二级标题：32px，加粗，白色偏暖
- 正文：20px（投屏最低可读），行高 1.6
- 注释/提示：16px，透明度 0.7
- 投屏最小字号建议：正文不低于 20px，卡片内不低于 18px，标题不低于 28px

### 组件风格
- 卡片：深色玻璃拟态（半透明 + 1px 浅色描边 + 圆角 12px + 轻微投影），展开时上浮高亮
- 按钮：主按钮（恒星金底、深色文字）；次级按钮（透明底、浅色描边）；圆角 8px，悬停发光
- 标签：分类色条（类地行星/巨行星/远日行星、自然天体/人造天体等）
- 提示框：模块内固定位置提示条，浅色底 + 对应状态色图标
- 反馈框：拖拽练习的"正确/错误"结果卡，正确绿、错误红，附一句解释
- 图表/3D 容器：全宽深色视窗，底部预留信息卡与图例位置

## 4. 模块详细说明
### 模块 M0 封面与导航
- 教学目的：呈现课题、建立沉浸氛围、提供全课导航
- 页面位置：页面顶部，全屏一屏
- 内部结构：中央大标题"地球的宇宙环境"→ 副标题（第一章 第一节 · 高中必修一）→ 下方"开始学习"按钮 → 顶部固定导航条（模块锚点）
- 首先看到什么：星空背景 + 发光大标题
- 强调什么：课题名与"宇宙感"氛围
- 交互入口位置：顶部导航条、中央开始按钮
- 反馈区域位置：导航条当前模块高亮
- 动效建议：标题淡入上浮、星点缓慢漂移
- 移动端注意事项：封面高度压缩，标题自适应缩小

### 模块 M1 宇宙概念
- 教学目的：理解宇宙的物质性、运动性与空间尺度
- 页面位置：封面之下
- 内部结构：上部演示区（"地球→太阳系→银河系→可观测宇宙"逐级放大动画，可重播）→ 下部概念卡（物质性、运动性、大爆炸背景一句话）
- 首先看到什么：逐级放大动画
- 强调什么：宇宙"无边无际、无始无终"
- 交互入口位置：演示区右下角"重播"按钮
- 反馈区域位置：动画播放结束后的状态提示
- 动效建议：缩放过渡动画，节奏舒缓（每级 1.5s）
- 移动端注意事项：动画以 2D 平铺代替全屏

### 模块 M2 天体卡片档案
- 教学目的：掌握星云、恒星、行星、卫星、流星体、彗星、行星际物质的特征
- 页面位置：M1 之下
- 内部结构：7 张卡片 3 列网格；每张卡片头部 = 图标 + 名称 + 展开箭头，点击后卡片展开显示特征条目（组成、特点、一句话形象比喻）
- 首先看到什么：整齐的卡片网格
- 强调什么：恒星（自身发光）、彗星（彗尾背向太阳）两个易错卡片可做角标提醒
- 交互入口位置：卡片头部整行可点击
- 反馈区域位置：展开区在卡片内部展开，展开状态箭头旋转
- 动效建议：展开高度过渡动画（max-height 或 grid-rows 过渡），一次只展开一张
- 移动端注意事项：网格降为 2 列

### 模块 M3 天体判别·流星案例
- 教学目的：用流星案例理解判别三条件
- 页面位置：M2 之下
- 内部结构：左侧分步示意图（流星体进入大气层→摩擦燃烧→流星现象→落到地面成陨石）；右侧三条件条目，随分步讲解逐个点亮
- 首先看到什么：流星划过大气层的示意图
- 强调什么："大气层外""是物质不是现象""独立个体"三条件逐条对应案例
- 交互入口位置："下一步"按钮推进分步
- 反馈区域位置：右侧条件区当前条目高亮 + 底部结论条"流星现象不是天体"
- 动效建议：流星拖尾动画、条件条目点亮
- 移动端注意事项：左右结构降为上下结构

### 模块 M3 · 随堂练习（拖拽分类）
- 教学目的：即时检测天体判别能力
- 页面位置：M3 模块内（随堂练习浮层）
- 内部结构：上方为 6~8 张可拖拽案例卡（如：月球、流星现象、太阳、哈雷彗星、人造卫星、陨石、火星、太空垃圾等）；下方两个分类框"天体""非天体"
- 首先看到什么：待分类卡片 + 两个明确的分类框
- 强调什么：分类框的语义与颜色区分（天体=星云青、非天体=提示橙）
- 交互入口位置：卡片本身可拖拽（触屏/点击场景降级为"先点卡片、再点目标框"）
- 反馈区域位置：卡片落入后立即变色（正确绿、错误红），并在下方结果条给出解释文字（如"陨石已落到地面，不属于天体"）
- 动效建议：拖拽跟随、落框弹跳、错误抖动
- 移动端注意事项：降级交互必须可用

### 模块 M4 天体系统层级
- 教学目的：理解天体系统的嵌套包含关系
- 页面位置：M5 之前
- 内部结构：居中嵌套圆环图（地月系最小 → 太阳系 → 银河系 → 可观测宇宙最大），点击或自动逐级放大，当前层级标签高亮
- 首先看到什么：中心"地月系"小圆环
- 强调什么：逐级包含关系与"相互吸引、相互绕转"
- 交互入口位置：点击圆环或"下一级"按钮
- 反馈区域位置：被点层级发光放大，其他层级变暗
- 动效建议：缩放聚焦动画（级间 0.8s）
- 移动端注意事项：圆环图整体缩放适配

### 模块 M5 太阳系与八大行星
- 教学目的：直观呈现八大行星分布、公转方向与相对位置
- 页面位置：M4 之下
- 内部结构：全宽 3D 视窗（太阳居中，八大行星沿轨道公转，公转方向一致）；点击行星弹出信息卡（名称、分类、一句话特征）；视窗右下角提供"自动/手动"切换与"重置视角"
- 首先看到什么：缓慢自转的太阳与沿轨道公转的行星
- 强调什么：公转方向一致（同向性）、轨道共面（俯视视角）
- 交互入口位置：3D 视窗内拖拽旋转、点击行星
- 反馈区域位置：行星信息卡在视窗下方或侧方弹出
- 动效建议：行星公转、太阳发光脉冲
- 移动端注意事项：3D 视窗高度压缩，保留手动旋转

### 模块 M6 行星的运动特征
- 教学目的：掌握同向性、近圆性、共面性三大运动特征
- 页面位置：M5 之下
- 内部结构："同向性、近圆性、共面性"三张特征卡片对照区；其下方为正方形"八大行星绕日公转"演示视窗（太阳居中、行星沿近似圆形轨道绕日公转），视窗底部提示条静态展示三性说明文字
- 首先看到什么：三张特征卡；向下滚动见公转演示
- 强调什么：公转方向一致（自西向东）、轨道近似圆形、轨道面几乎在同一平面
- 交互入口位置：特征卡悬停显示说明；公转演示可拖拽旋转视角、滚轮缩放（可旋至轨道平面正侧视观察共面性；点击行星无额外简介）
- 反馈区域位置：悬停高亮当前特征卡；公转演示底部提示条展示"方向一致、轨道近似圆形、轨道面几乎共面"说明
- 动效建议：切换淡入淡出；公转采用匀速圆周运动，相机约 70° 俯角使轨道从视觉上近似圆形
- 移动端注意事项：三列降为单列；视窗保持正方形（宽取 `min(100%, 960px)` 居中）

### 模块 M7 地球的普通性和特殊性
- 教学目的：由运动特征（同向性、近圆性、共面性）与结构特征（体积、质量）说明地球并无特殊之处，归纳出"地球是一颗普通的行星"；再由"目前已知唯一存在高级智慧生命"点明其"特殊"；并引出 M8 生命条件
- 页面位置：M6 之下、M8 之前
- 呈现形式：可视化 + 极简文字（与全课 M4/M5/M6/M8 的"示意图 + 一句说明 + 一行图注"一致，不做文字堆砌）
- 内部结构：
  · 主视觉「八大行星」横向 3D 行星模型：八颗行星按相对大小（**压缩比例**：半径取相对大小的平方根，示意非真实比例）由近及远排列为标准 3D 球体模型（与 M5 太阳系、M6 公转演示同一套球面贴图 / 光照 / 材质，缓慢自转），地球以「亮色 + 加粗」名称标签标注（**不使用金色** —— 金色在本课设计系统里代表「选中态」，会造成误解；球体不常驻高亮 / 光环）；下方一行图注"地球，只是太阳系八颗行星中的一颗。"
  · 两条证据卡（M6 卡片范式）：① 运动特征——太阳系绕日公转 3D 模型（**侧面俯视**：相机与轨道面约成 38° 夹角，太阳居中，八大行星在同一平面内同向沿近圆轨道公转，呈现同向性 / 近圆性 / 共面性），配一句说明与图注"同向性 · 近圆性 · 共面性"；② 结构特征——四颗类地行星按体积（立方根）换算的相对大小 3D 行星模型，地球以亮色加粗名称标注，配一句说明与图注"与类地行星同量级"
  · 结论：普通性结论条（青）"所以，地球是一颗普通的行星。" → 转折语（金，居中）"然而——" → 特殊性块（金）：陈述句（目前已知唯一存在高级智慧生命）+ 特殊性结论 + 指向 M8 的桥接句
- 首先看到什么：八大行星横向 3D 行星模型，地球在第三位以亮色加粗名称标注
- 强调什么：地球只是八颗行星中的一颗（普通）；经"然而"转折后，目前已知唯一存在高级智慧生命（特殊）
- 交互入口位置：无点击入口；行星 3D 模型缓慢自转，指针悬停行星时轻微提亮并切换为指针光标（逐段向下阅读）
- 反馈区域位置：悬停行星轻微提亮 + 光标变化；地球以亮色加粗名称标签标注，普通结论条（青）与特殊性块（金）以颜色区分，转折语以金色居中承担"普通 → 特殊"的视线引导
- 动效建议：八大行星与类地行星模型缓慢自转，运动特征卡的太阳系模型同向公转；尊重 `prefers-reduced-motion`（只渲染静态一帧）
- 移动端注意事项：≤900px 证据卡由两列降为单列；≤640px 收紧模型舞台高度与卡片内边距

### 模块 M8 地球存在生命的原因
- 教学目的：掌握外部+自身条件的因果链
- 页面位置：M7 之下
- 内部结构：外部条件与自身条件分开绘制为两个独立面板——面板一"外部条件"（太阳壮年→光照稳定；行星各行其道→环境安全），面板二"自身条件"（日地距离适中+自转公转周期适宜→适宜温度→液态水；体积质量适中→引力→适宜大气；内部升温→水汽→成云致雨→海洋→生命摇篮）；两组因果链默认完整显示，无分步动画
- 首先看到什么：外部条件、自身条件两个分组（各自"条件—结果"链完整呈现）
- 强调什么："条件—结果"箭头对应关系
- 交互入口位置：无（已删除"下一步"按钮）
- 反馈区域位置：底部结论条"外部 + 自身共同作用 → 生命诞生"
- 动效建议：不设点亮/描线动画，内容静态完整呈现
- 移动端注意事项：双分支在窄屏改为纵向串联

### 模块 M9 复习与总结
- 教学目的：收束知识结构，衔接课后复习
- 页面位置：M8 之下
- 内部结构：单向树状思维导图（根在左、逐级向右展开；宇宙 → 天体 / 天体系统 → 太阳系 → 地球），节点可点击展开/收起，控制条可逐层展开；部分叶子节点可点击跳到对应模块；底部提供"进入复习模式"按钮（隐藏讲解文字、仅留结构图与复习文档，供自学巩固）
- 首先看到什么：知识树主干（根 + 两个一级分支），按讲解节奏逐层铺开
- 强调什么：知识之间的层级关系
- 交互入口位置：节点展开/收起、控制条「展开下一层 / 全部展开 / 全部收起」、带下划线的叶子节点（点击跳转对应模块）、"进入复习模式"按钮
- 反馈区域位置：节点 `+ / −` 符号变化；控制条右侧显示"已展开 X / Y 层"
- 动效建议：节点与连线淡入（展开时）
- 移动端注意事项：结构图不缩放，改为横向滚动查看

### 模块 拓展材料浮层（每模块右上角按钮）
- 教学目的：学有余力学生自主学习补充材料
- 页面位置：全课每个模块右上角"⊕ 拓展"入口
- 内部结构：模态浮层（深色底、玻璃卡片），内容按模块组织（如 M2 拓展：天体知识趣闻；M5 拓展：其他行星系案例；M6 拓展：行星数据对比），右上角关闭按钮
- 首先看到什么："⊕ 拓展"小按钮（弱化呈现，不干扰主线）
- 强调什么：与当前模块相关的补充内容
- 交互入口位置：模块右上角、浮层内关闭按钮
- 反馈区域位置：浮层打开/关闭过渡动画
- 动效建议：浮层淡入 + 轻微上浮
- 移动端注意事项：浮层占满屏幕

## 5. 设计约束
- 必须保留的设计点：宇宙感深色底色；卡片档案展开交互；拖拽练习的即时对错反馈；层级逐级放大；M8 因果链双分支结构；每模块"⊕ 拓展"入口；投屏级字号。
- 可降级的设计点：星点背景动画（可静态星点替代）；3D 太阳系（可降级为 2D 轨道动画）；逐级放大动效（可简化为静态嵌套图）。
- 应避免的视觉问题：背景过亮导致文字对比不足；色彩超过 6 个主色；动效过多造成眩晕；卡片一次全部展开造成信息堆叠；发光效果盖过正文。
- 对技术实现的重点要求：卡片展开、拖拽分类、层级放大、因果链分组展示、3D 视窗、拓展浮层六类交互必须可用；所有资源离线可运行；桌面投屏优先，分辨率 1920x1080 下布局不破版。
