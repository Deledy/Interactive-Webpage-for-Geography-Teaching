# 开发文档：地球的宇宙环境 互动教学网页

本文件是 AI 编程工具可直接执行的开发说明书。开发者（或 AI 编程工具）应严格按照本文件实现，所有交互、视觉、技术约束以本文为准；与本文冲突的设想一律不实现。

## A. 项目概述
- 项目名称：地球的宇宙环境（人教版高中必修一 · 第一章第一节）互动教学网页
- 页面定位：课堂讲授 + 学生自学 + 复习巩固 + 公开课展示 的多模块单页教学网页
- 使用对象：高一学生（课堂听讲 / 课后自学）、地理教师（投屏讲授 / 公开课）
- 使用场景：教室投屏（1920x1080 优先）、学生个人电脑浏览；不要求手机端优先，但页面在窄屏下不得破版、核心交互须可用
- 开发目标：围绕 10 条核心知识点（宇宙概念、天体概念与 7 类常见天体、天体类型、判别三条件、天体系统概念与层级、八大行星、三大运动特征、地球存在生命的原因）实现"讲解 + 互动 + 复习 + 拓展"一体化网页
- 本次范围：M0~M10 共 11 个模块，P0/P1 全部实现，P2 不实现（仅按需占位）

## B. 开发优先级
- P0 必须实现：M0 封面导航；M1 宇宙概念；M2 天体卡片档案（点击展开）；M3 流星案例分步；M4 拖拽分类互动（含点击降级）；M5 天体系统层级（逐级放大）；M7 行星运动三性；M8 地球生命条件因果链（外部/自身分组静态呈现）；M10 拓展浮层；全局深空视觉系统；离线可运行；投屏字号达标。
- P1 建议实现：M6 太阳系演示（默认实现 2D SVG 轨道图；若 WebGL 环境就绪且已本地化 Three.js，则启用 3D 视窗，两者共存，自动切换）；M9 复习与总结（结构图折叠 + 复习模式切换）；星点背景动画（无 JS 时降级为静态星点）。
- P2 可选增强（本轮不实现）：3D 多级天体系统模型（卫星绕行星）；行星严格按比例建模；例题模块；统计图表。以上仅预留入口/占位，不做功能。

## D. 模块开发说明

### 模块 M0 封面与导航
- 教学目的：呈现课题、建立沉浸氛围、提供全课导航。
- 页面内容：中央大标题"地球的宇宙环境"，副标题"第一章 第一节 · 高中必修一"，"开始学习"按钮；顶部固定导航条含全部模块锚点（封面 / 宇宙 / 天体 / 判别 / 练习 / 层级 / 太阳系 / 行星 / 生命 / 复习）。
- 界面布局要求：封面占满首屏（100vh）；导航条在滚动后常驻顶部，半透明深色底。
- 交互逻辑：点击锚点平滑滚动至对应 section；滚动时当前所在模块在导航中高亮（IntersectionObserver）。
- 反馈要求：导航当前项高亮（恒星金文字 + 底部发光条）。
- 技术实现建议：`scroll-behavior: smooth` + IntersectionObserver；导航项用 `data-target` 映射 section id。
- 移动端要求：封面文字自适应缩小，导航可横向滚动。
- 可降级方案：无 JS 时导航退化为普通锚点跳转。
- 验收标准：点击每个导航项可到达对应模块；滚动时导航正确高亮；封面在 1920x1080 下完整呈现。

### 模块 M1 宇宙概念
- 教学目的：理解宇宙的物质性、运动性，建立空间尺度。
- 页面内容：演示区（"地球→太阳系→银河系→可观测宇宙"逐级放大动画，共 4 级）；概念卡 3 张（物质性：宇宙由物质组成；运动性：天体在运动；起源一句话：约 137 亿年前大爆炸，空间无边无际、时间无始无终）。
- 界面布局要求：上部演示区（高度约 50vh），下部三张概念卡横向排列。
- 交互逻辑："播放/重播"按钮控制动画；动画按 0.8s 间隔逐级放大后停留 1.2s。
- 反馈要求：动画结束显示"到达可观测宇宙边界"提示条；重播按钮重新开始。
- 技术实现建议：CSS transform scale 阶梯放大 + JS setTimeout 时序；可用同一中心点逐级放大模拟"向深处飞行"。
- 移动端要求：动画容器高度压缩，字号缩小。
- 可降级方案：无 JS 时静态展示 4 级名称列表。
- 验收标准：动画 4 级完整播放；可重播；概念卡文字无截断。

### 模块 M2 天体卡片档案
- 教学目的：掌握星云、恒星、行星、卫星、流星体、彗星、行星际物质 7 类天体的特征。
- 页面内容：7 张卡片（3 列网格）；卡片头部 = 图标 + 名称 + 展开箭头；展开内容 = 组成 + 特点 + 一句话比喻；恒星、彗星卡片头部加"易错"角标。
- 界面布局要求：3 列网格（≤1024px 降 2 列）；卡片圆角 12px，深色玻璃底。
- 交互逻辑：点击头部展开/收起；同一时间最多一张展开（点开新卡时自动收起旧卡）。
- 反馈要求：展开区域淡入；箭头旋转 180°；头部高亮。
- 技术实现建议：数据渲染自 `lessonData.celestialBodies`；展开用 `grid-template-rows: 0fr → 1fr` 过渡（内部容器 `overflow:hidden`）。
- 移动端要求：网格降 2 列。
- 可降级方案：无 JS 时全部卡片默认展开。
- 验收标准：7 张卡片内容完整且与教学设计知识点一致；点击展开收起正确；一次仅一张展开。

### 模块 M3 天体判别·流星案例
- 教学目的：用流星案例理解判别三条件（是物质不是现象 / 地球大气层之外 / 独立个体）。
- 页面内容：左侧分步示意图（3 步：流星体进入大气层 → 摩擦燃烧形成流星现象 → 未燃尽落至地面成陨石）；右侧三条件条目区；底部结论条"流星现象发生在大气层内，不是天体；落到地面的陨石也不是天体"。
- 界面布局要求：左右布局（左 6 右 4 栅格）；窄屏上下布局。
- 交互逻辑："下一步"按钮推进 stepIndex（0→1→2→完成，完成后按钮变"重新开始"）；每步点亮对应条件条目与示意图状态。
- 反馈要求：当前步骤节点发光；条件条目逐条点亮（第一步点亮"是物质不是现象"，第二步点亮"地球大气层之外"，第三步点亮"独立个体"）；结论条在最后一步显示。
- 技术实现建议：SVG 绘制大气层弧线与流星路径；CSS 动画模拟流星拖尾；条件点亮用类名切换。
- 移动端要求：上下布局，示意图在上。
- 可降级方案：无 JS 时静态展示完整图与三条件。
- 验收标准：3 步推进正确；条件与步骤对应关系正确；结论条文案准确。

### 模块 M4 拖拽分类互动
- 教学目的：即时检测"天体/非天体"判别能力，强化易错点。
- 页面内容：待分类案例卡 9 张（月球 / 流星现象 / 太阳 / 哈雷彗星 / 在轨人造卫星 / 陨石 / 火星 / 太空垃圾 / 闪电）；两个分类框："天体"（星云青）与"非天体"（提示橙）；下方结果统计条。
- 界面布局要求：上方卡片区（流式排列），下方两个并排分类框（各占一半宽度）。
- 交互逻辑：主交互为 HTML5 拖拽（dragstart/dragover/drop）；检测到触屏或无 DragEvent 支持时启用降级：先点卡片（选中高亮）再点目标框。9 张卡片的正确答案：月球=天体、流星现象=非天体、太阳=天体、哈雷彗星=天体、在轨人造卫星=天体、陨石=非天体、火星=天体、太空垃圾=天体、闪电=非天体。
- 反馈要求：放对 → 卡片移入框并变绿 + 结果条"正确：<一句解释>"；放错 → 卡片弹回待分类区并红色抖动 + 结果条"再想想：<一句解释>"；全部完成显示"全部完成，正确 X/9"。解释文案：陨石"已落到地面，不属于天体"；流星现象"发生在大气层内，是现象不是天体"；闪电"是现象不是天体"；在轨人造卫星"是太空中运行的人造天体"；太空垃圾"在太空中运行，是人造天体"。
- 技术实现建议：拖拽与点击降级共用 `judge(cardId, target)` 判定函数；状态存 `state.dragResults`。
- 移动端要求：点击降级模式必须可用。
- 可降级方案：无 JS 时显示静态题目列表与答案（打印友好）。
- 验收标准：9 张卡片判定逻辑正确；即时对错反馈与解释文案正确；点击降级可用；可全部完成并统计。

### 模块 M5 天体系统层级
- 教学目的：理解"可观测宇宙—银河系—太阳系—地月系"的嵌套包含关系。
- 页面内容：嵌套圆环图（由内到外：地月系 → 太阳系 → 银河系 → 可观测宇宙），每层标签含名称与一句话说明（如地月系：地球与月球相互绕转）；每层附"同级案例"文本（如太阳系层级可展示"其他恒星系：半人马座 α 星系"，银河系层级展示"河外星系：仙女座星系"）。
- 界面布局要求：居中圆环图（SVG，视口 80% 高度），下方层级文字说明区。
- 交互逻辑：点击某层 → 该层放大聚焦并发光，其余层变暗；或"下一级/上一级"按钮顺序切换（默认从地月系开始）。
- 反馈要求：当前层发光放大；说明区显示该层名称、包含内容与同级案例。
- 技术实现建议：SVG circle 嵌套，`<g>` 分组 transform 缩放聚焦；层级数据存 `lessonData.hierarchy`。
- 移动端要求：圆环图整体缩放适配，说明区在下方。
- 可降级方案：无 JS 时显示静态嵌套图（各层全部可见）。
- 验收标准：4 层名称与包含关系正确；点击聚焦正确；同级案例文本正确显示。

### 模块 M6 太阳系与八大行星
- 教学目的：直观呈现八大行星分布、公转方向与相对顺序。
- 页面内容：视窗中央太阳，八大行星沿各自轨道绕转（公转方向一致，自西向东）；点击行星弹出信息卡（名称、分类、一句话特征）；视窗下方图例（行星名称与颜色）；"自动/手动"切换与"重置视角"按钮（3D 版）；"非按比例"标注。
- 界面布局要求：全宽视窗（高度约 60vh）；信息卡出现在视窗底部或侧边。
- 交互逻辑：2D 版：SVG 椭圆轨道 + 行星球沿轨道匀速运动（requestAnimationFrame），点击行星球高亮并显示信息卡。3D 版（WebGL 可用且已引入本地 Three.js 时启用）：OrbitControls 拖拽旋转视角；点击行星球（Raycaster）显示信息卡。WebGL 检测失败自动切换 2D。
- 反馈要求：选中行星高亮 + 信息卡显示；hover 行星时发光提示。
- 技术实现建议：数据存 `lessonData.planets`（名称/分类/颜色/轨道半径/公转周期比例/特征）；颜色：水星 #b0b7c6、金星 #e6c87a、地球 #4f9df7、火星 #d96c4f、木星 #d9a05b、土星 #e3c98a、天王星 #7fd4d4、海王星 #5a7fe0。
- 移动端要求：视窗高度压缩；信息卡不遮挡行星。
- 可降级方案：WebGL 不可用 → 2D SVG 轨道图（必须保证可用）；无 JS 时显示静态行星列表。
- 验收标准：八大行星顺序与分类正确；公转方向一致；点击行星出信息卡；2D 版在无 WebGL 环境可运行；标注"非按比例"。

### 模块 M7 行星的运动特征
- 教学目的：掌握同向性、近圆性、共面性三大运动特征。
- 页面内容：三张特征卡（同向性：八大行星绕日公转方向自西向东；近圆性：行星公转轨道近似圆形；共面性：行星轨道面几乎在同一平面）+ 其下方正方形"八大行星绕日公转"演示（太阳居中、行星沿近似圆形轨道绕日公转，直观呈现三性）；演示上方不设标题与长描述，三性说明文字放在演示视窗下方提示条内。
- 界面布局要求：三卡横排（1/3 宽 ×3）；公转视窗为正方形（宽 `min(100%, 960px)` 居中、`aspect-ratio: 1/1`）；窄屏三卡降为单列、视窗保持正方形。
- 交互逻辑：特征卡悬停高亮；公转演示可拖拽旋转视角（OrbitControls，极角范围 `0.15 ~ π/2`，可旋至轨道平面正侧视观察共面性）、滚轮缩放（无点击简介功能）；离开视口自动暂停动画，`prefers-reduced-motion` 时静态渲染。
- 反馈要求：悬停特征卡高亮（青蓝边框）；演示底部提示条静态展示"方向一致、轨道近似圆形、轨道面几乎共面"三性说明。
- 技术实现建议：Three.js 绘制太阳与八大行星（纹理贴图）、`LineLoop` 圆形轨道、`RingGeometry` 光环；相机约 70° 俯角俯视轨道平面，使轨道从视觉上近似圆形；2D 降级图使用正方形 viewBox 保证圆形不被拉伸。
- 移动端要求：单列上下布局，视窗保持正方形。
- 可降级方案：WebGL 不可用时降级 2D SVG 同心圆轨道图（行星沿轨道移动）；无 JS 时显示静态占位说明。
- 验收标准：三性名称与解释正确；三张特征卡渲染正常；演示上方无标题/长描述文字；公转模型轨道视觉上近似圆形、公转方向一致、轨道面共面；视窗为正方形；点击行星不弹出简介；2D 降级与无 JS 占位可用。

### 模块 M8 地球存在生命的原因
- 教学目的：掌握外部条件与自身条件两条因果链。
- 页面内容：将外部条件与自身条件分开绘制为两个独立面板（不设分步动画）。外部条件（太阳处于壮年→光照稳定，生命演化连续；大小行星各行其道→互不干扰，宇宙环境安全）；自身条件（日地距离适中、自转公转周期适宜→温度适宜，水以液态存在；体积质量适中→引力足够，形成适宜大气；原始地球内部升温产生水汽→成云致雨汇聚成海，孕育生命）；底部结论条"外部 + 自身条件共同作用 → 地球适宜生命存在"。
- 界面布局要求：两个独立圆角矩形面板并排绘制，各含标题与"条件→结果"因果链（横向节点 + 箭头），互不共用容器；窄屏两面板改为纵向排列；所有因果链默认完整显示。
- 交互逻辑：无分步交互；"下一步"按钮及逐条点亮逻辑已删除。
- 反馈要求：不设点亮/描线动画，节点与箭头默认完整呈现。
- 技术实现建议：节点 + 连线直接静态渲染（div 结构）；数据存 `lessonData.lifeConditions`，JS 按数据渲染，无 JS 时展示同构静态 HTML。
- 移动端要求：窄屏纵向排列，箭头向下。
- 可降级方案：无 JS 时显示与 JS 渲染同构的完整分组静态图。
- 验收标准：5 条因果链"条件→结果"对应关系与教学设计一致；外部/自身两组分开呈现且全部完整可见；页面不含分步动画与"下一步"按钮。

### 模块 M9 复习与总结
- 教学目的：收束全课知识结构，支持课后自学复习。

- 移动端要求：结构树允许横向缩放查看。
- 可降级方案：无 JS 时显示完整静态结构图。
- 验收标准：结构树层级正确；折叠展开正常；复习模式正确隐藏讲解文字且保留练习。

### 模块 M10 拓展材料浮层
- 教学目的：为学有余力学生提供自主学习补充材料。

- 移动端要求：浮层全屏化。
- 可降级方案：无 JS 时入口隐藏。
- 验收标准：每个入口可打开对应拓展内容；关闭方式（按钮/遮罩/Esc）全部可用；内容与学科知识一致。

## E. 全局视觉与交互规范
- 色彩与风格要求：深空宇宙感。页面底色径向渐变 `#0B1026 → #1A1040 → #0A0A18`；卡片深色玻璃（`rgba(255,255,255,0.06)` 底、`rgba(255,255,255,0.14)` 描边、圆角 12px）；主强调恒星金 `#FFD54F`（标题、重点、选中态）；次级强调星云青 `#4FC3F7`（次级、链接、行星动效）；状态色：正确 `#66BB6A`、错误 `#EF5350`、提示 `#FFB74D`。全局背景叠加静态星点层（可用 CSS 径向渐变点阵或小型 canvas 绘制）。
- 字体字号层级：主标题 48px+ 加粗；二级标题 32px 加粗；正文 20px、行高 1.6（投屏最小）；注释/提示 16px、透明度 0.7；投屏最小字号：正文不低于 20px、卡片内不低于 18px、标题不低于 28px。字体体系：正文/界面使用思源黑体（`--font-sans`，内置 400/700 两档子集）；课程名/封面大标题使用思源宋体（`--font-serif`，900 Heavy 一档子集）。字体子集由 `scripts/subset-fonts.mjs` 按本课实际用字生成，构建时全部 base64 内联进单文件（保证 file:// 双击离线可用）；系统已装思源字体时优先 `local()` 命中，未安装时回退内联子集，再回退系统默认字体（微软雅黑/宋体）。
- 留白与信息密度要求：模块间留白不小于 80px；单个模块内最多呈现 3 个视觉层级；卡片内正文行宽控制在 60~75 字符。
- 按钮与反馈状态要求：主按钮恒星金底深色字、圆角 8px、悬停发光；次级按钮透明底浅色描边；禁用态降低透明度 0.4；反馈条（正确/错误/提示）统一在模块底部固定位置，左图标右文字。
- 动效使用原则：动效总时长 ≤ 0.4s（除 M1 逐级放大演示与 M6 公转动画外）；尊重 `prefers-reduced-motion`；动效只用于"状态变化提示"，不做无意义装饰动画。
- 可读性要求：正文与背景对比度 ≥ 4.5:1；不得使用低对比度细字；重点知识使用"恒星金高亮 + 图标"双重强调而非仅靠颜色。
- 投屏适配要求：设计基准 1920x1080；正文 20px+；交互按钮不小于 44px 高；避免页面最右侧放置关键内容（投影幕布边缘裁切风险）。

## F. 技术约束
- 是否单文件 HTML：否。采用多文件静态页面：`index.html` + `css/style.css` + `js/main.js` + `js/lesson-data.js` + `libs/`（Three.js 本地文件，可选）。
- 是否允许外部 CDN：不允许。所有资源必须本地化，页面不得发起任何网络请求（离线硬约束）。
- 是否要求离线运行：是。双击 `index.html`（file:// 协议）或静态服务器均可完整运行；Three.js 若启用必须下载至 `libs/` 本地引用。
- 是否优先兼容手机：否（用户明确不需要优先手机端）；但窄屏不得破版，触屏拖拽必须有点击降级。
- 推荐技术栈：原生 HTML/CSS/JS + SVG；仅 M6 3D 版使用 Three.js（本地化，程序化球体与轨道，无需纹理）。
- 不建议使用的技术：React/Vue 等框架；CDN 引用的任何库；远程 CDN 加载的 Web 字体（离线硬约束下禁止，仅允许本地子集化 + base64 内联的 Web 字体，见 E 字体体系）；需要后端或网络的任何能力；Canvas 全页重绘（仅星点背景可用）。
- 字体维护要求：文案变更后必须重跑 `npm run fonts`（scripts/subset-fonts.mjs）重新生成字体子集，并在 `docs/06_资源引用.md` 保持登记；新增/替换字体须同步更新 `lesson.json` 的 `resources`。

## G. 开发顺序建议
1. 骨架与视觉系统：搭建 `index.html` 全部 section 结构、`css/style.css` 色彩变量与基础组件样式、`js/lesson-data.js` 数据对象、星点背景；接通 M0 导航与滚动高亮。
2. 讲解模块：M1 宇宙概念、M2 天体卡片、M3 流星案例、M7 三性与公转演示、M8 分组静态因果链（依次为低复杂度静态 + 轻交互）。
3. 互动模块：M4 拖拽分类（含点击降级）、M5 层级聚焦。
4. 太阳系：先实现 M6 2D SVG 轨道图并验收；再接入 Three.js 本地库实现 3D 版与 WebGL 检测切换。
5. 收尾：M9 复习模式、M10 拓展浮层、无 JS 降级态、投屏字号与间距检查、验收清单自测。
