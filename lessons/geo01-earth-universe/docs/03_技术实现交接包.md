# 技术实现交接包

课题：第一章 宇宙中的地球 · 第一节 地球的宇宙环境

## 1. 技术路线总览
- 实现形式：多文件静态页面。单页长页面（index.html）+ 本地依赖目录。原因：3D 太阳系需要 Three.js 且必须离线运行，库文件需本地化，故不宜强行塞进单文件 HTML。
- 推荐技术栈：原生 HTML + CSS + JavaScript（主逻辑）+ Three.js（仅 M6 太阳系 3D 模块）+ SVG（M5 层级图、M8 因果链）。
- 是否依赖外部库：是（仅 Three.js 一个，本地化，不引 CDN）。
- 是否支持离线：是。所有资源（含 Three.js、字体、图标）本地化；页面无任何网络请求依赖。
- 是否优先移动端适配：否（用户明确不需要优先手机端），但保留基础可用性（布局可随视口收缩，触屏拖拽降级为点击选择）。

## 3. 页面结构建议
- 建议 DOM 结构：
```
<body>
  <canvas id="starfield">   <!-- 全局星点背景，固定定位 -->
  <header id="nav">         <!-- M0 顶部导航，锚点 + 滚动高亮 -->
  <main>
    <section id="cover">    <!-- M0 封面 -->
    <section id="universe"> <!-- M1 宇宙概念 -->
    <section id="celestial"> <!-- M2 天体卡片档案 -->
    <section id="meteor">   <!-- M3 流星案例 -->
    <section id="drag">     <!-- M4 拖拽分类 -->
    <section id="hierarchy"><!-- M5 天体系统层级 -->
    <section id="solar">    <!-- M6 太阳系 3D -->
    <section id="planets">  <!-- M7 分类与三性 -->
    <section id="life">     <!-- M8 生命条件 -->
    <section id="review">   <!-- M9 复习总结 -->
  </main>
  <footer>                  <!-- 版权/课时信息 -->
  <div id="extend-modal">   <!-- M10 拓展浮层 -->
</body>
```
- 模块组织顺序：M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M9，与教学流程 S1~S6 一致（拖拽练习 M4 紧随判别知识 M3，教学上属于 S5 但位置紧随更利于知识衔接，总控已确认）。
- 是否需要锚点导航：是（顶部导航条 + section id + 平滑滚动）。
- 是否需要状态管理：不需要引入框架；用单例 JS 对象（如 `window.App = {}`）管理：当前展开卡片、练习得分、当前层级、当前点亮节点、复习模式开关。
- 是否需要本地数据对象：是。建立 `lessonData` 数据对象，集中管理卡片、案例、行星、层级、因果链、拓展内容等全部教学数据，便于教师日后增删改。

## 4. 样式组织建议
- 是否使用 CSS 变量：是。在 `:root` 中定义色彩系统（见页面设计交接包第 3 节）与间距、圆角、字号、动效时长变量，保证全页统一、教师可改。
- 响应式断点建议：桌面（默认，≥1280px 为设计基准）；平板（≤1024px，网格降列）；窄屏（≤768px，仅保证可用，非优先）。
- 卡片/按钮/提示框统一类名建议：`.card`、`.card--expand`、`.btn`、`.btn--primary`、`.btn--ghost`、`.tag`、`.hint`、`.feedback`、`.badge`（如 `badge--correct` / `badge--wrong`）。
- 动效实现建议：优先 CSS transition/transform/keyframes；SVG 路径描线用 `stroke-dashoffset`；3D 场景用 Three.js requestAnimationFrame；全局 `prefers-reduced-motion` 媒体查询降级动效（照顾公开课场景的兼容性）。

## 5. 交互逻辑说明
### 模块 M2 天体卡片
- 用户操作：点击卡片头部。
- 触发逻辑：若该卡已展开则收起；否则收起其他卡片、展开本卡。
- 状态变化：`state.expandedCard = cardId`；箭头图标旋转；内容区高度过渡。
- 反馈方式：展开内容淡入，头部高亮。
- 容错处理：重复点击同一卡片 = 收起；页面无 JS 时卡片内容默认全部展开（渐进增强）。

### 模块 M3 流星案例分步
- 用户操作：点击"下一步"（最后一步变为"重新开始"）。
- 触发逻辑：`stepIndex++`，对应更新示意图状态与右侧条件点亮。
- 状态变化：`state.meteorStep`；条件条目按步骤逐个高亮。
- 反馈方式：当前步骤节点发光，结论条在最后一步显示"流星现象不是天体"。
- 容错处理：步骤越界自动回绕；键盘方向键支持（辅助）。

### 模块 M4 拖拽分类
- 用户操作：拖拽案例卡到"天体/非天体"框；触屏/降级模式为先点卡片、再点目标框。
- 触发逻辑：`dragover` 阻止默认、`drop` 判定归属；点击降级：`selectedCard` 置位后点框判定。
- 状态变化：`state.dragResults[cardId] = { correct: boolean }`；卡片移入框内；全部完成后显示完成态。
- 反馈方式：正确 → 卡片绿色高亮 + 结果条"正确：解释"；错误 → 红色抖动 + 结果条"再想想：解释"，卡片留在待分类区可重试。
- 容错处理：拖拽 API 不可用（触屏/老浏览器）时自动启用点击降级；统计结果条累计正确数。

### 模块 M5 层级聚焦
- 用户操作：点击某一层级圆环，或点击"下一级/上一级"按钮。
- 触发逻辑：点击层级 → 以该层级为中心放大；按钮 → 沿 地月系→太阳系→银河系→可观测宇宙 顺序切换。
- 状态变化：`state.level = 0..3`；SVG 各圆环 opacity/transform 更新。
- 反馈方式：当前层级放大且发光，其余层级变暗显示包含关系。
- 容错处理：动画期间禁用连续点击（防抖）；无 JS 时显示静态嵌套图。

### 模块 M6 太阳系 3D
- 用户操作：拖拽旋转视角（OrbitControls）；点击行星弹出信息卡；"自动/手动"切换；"重置视角"。
- 触发逻辑：行星球体注册 click 事件（Raycaster 射线检测）；轨道用圆环线（RingGeometry/Line）绘制；行星沿圆轨道自西向东公转（统一角速度方向）。
- 状态变化：`state.solarAuto = true/false`；`state.selectedPlanet`；每帧更新行星位置与自转。
- 反馈方式：选中行星信息卡显示名称、分类、特征；行星 hover 时发光提示可点击。
- 容错处理：WebGL 不可用（老设备/部分投影）→ 检测失败自动降级为 2D SVG 轨道图模块；帧率过低时自动关闭背景特效。

### 模块 M8 因果链
- 用户操作：点击"下一步"逐条点亮。
- 触发逻辑：`state.lifeStep` 递增，对应点亮"条件 → 结果"节点并描画箭头。
- 状态变化：节点类名切换（`.lit`）；箭头 `stroke-dashoffset` 归零动画。
- 反馈方式：点亮节点高亮 + 底部结论条逐步更新。
- 容错处理：步骤越界回绕；无 JS 时全部点亮显示完整图。

### 模块 M10 拓展浮层
- 用户操作：点击任意"⊕ 拓展"入口打开；点击遮罩或关闭按钮关闭。
- 触发逻辑：入口 data 属性记录来源模块，浮层渲染对应内容；Esc 关闭。
- 状态变化：`state.modal = { open: bool, sectionId }`；浮层内容区切换。
- 反馈方式：浮层淡入上浮；关闭后回到原位置。
- 容错处理：内容不存在时显示"敬请期待"占位；连续快速点击防抖。

## 7. 风险与降级方案
- 高风险点：
  1. Three.js 本地化体积（min 版约 600KB），首次加载略慢；若严格追求单文件则无法内置。
  2. 部分教室投影/旧电脑 WebGL 不可用或性能差，3D 视窗可能白屏或掉帧。
  3. HTML5 拖拽在触屏设备不可用，公开课若用触屏大屏会失效。
- 推荐降级方案：
  1. 3D 不可用 → 自动检测 WebGL（`canvas.getContext('webgl')` 为空）后切换为 2D SVG 太阳系轨道图（行星沿椭圆轨道公转 + 点击信息卡），教学价值基本保留。
  2. 拖拽不可用 → 自动降级为"先点卡片、再点目标框"的点击选择模式，反馈逻辑不变。
  3. 体积问题 → 如后续需要，可将 Three.js 精简打包（tree-shaking）或仅保留核心场景。
- 不建议实现项：例题模块、真实图片素材、统计图表（用户已明确暂不实现，仅留占位）；不引入 React/Vue 等框架；不做离线 PWA 打包（当前静态目录拷贝即离线）。
