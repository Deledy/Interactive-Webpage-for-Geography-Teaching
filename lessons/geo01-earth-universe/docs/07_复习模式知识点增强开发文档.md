## 0. 结论与要点

1. **阅读式文档**：卡片网格 → `review-sec` / `review-line` 的自然阅读排版。
2. **内容严格还原**：按 docx「一～五」逐节录入；删除 docx 没有的「宇宙的概念」等自增内容。

4. **复制保护**：答案只存在于伪元素中，且挖空按钮 `user-select: none`——浏览器复制/剪贴板**不包含**伪元素内容，因此选中复制时答案不会出现（此前答案写在 DOM 文本里，会被复制）。

8. **空与空的间隔**：相邻挖空之间插入间隔符号（顿号「、」／箭头「→」），并以 `sep` 片段单独成 span，前后各留 6px 间距，形成呼吸感。

export type ReviewSegment =
  | { kind: 'text'; text: string }
  | { kind: 'blank'; answer: string }
  | { kind: 'sep'; text: string }        // 空与空之间的间隔符号（、／→）

export interface ReviewJudgeItem { name: string; isCelestial: boolean; explain: string }

  | { kind: 'line'; prefix?: string; segments: ReviewSegment[] }  // 一行：前缀 + 文本/挖空/间隔符

## 5. 复制保护实现

- 挖空渲染为 `<button class="cloze-blank" data-answer="…">`（**按钮内无文本**）。
- 答案由 `.cloze-blank::after { content: attr(data-answer) }` 呈现，未揭示时 `color: transparent`。
- `.cloze-blank { user-select: none }`：选中段落时跳过空位。
- 浏览器复制不包含伪元素生成内容 → 复制结果只有题干文字，无答案。
