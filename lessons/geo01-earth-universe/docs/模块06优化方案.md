请不要修改当前页面的整体布局、背景、星空效果、行星位置、分组结构和已有功能。

本次只优化两个部分：

1. 行星类型和行星名称的视觉表达；
2. 点击行星后，下方信息面板的展示效果。

请尽量复用现有代码和样式，只针对相关组件进行修改。

一、行星类型的设计

当前页面中需要更清晰地区分三类内容：

- 类地行星：水星、金星、地球、火星
- 巨行星：木星、土星
- 远日行星：天王星、海王星

请将“行星类型”设计为分组标题或分类标签，而不是普通的小文字。

建议：

1. 每个分组区域顶部保留一个醒目的分类标题：
- 类地行星
- 巨行星
- 远日行星

2. 分类标题采用胶囊标签样式：
   - 圆角：999px
   - 内边距：8px 16px
   - 边框：1px solid
   - 背景使用半透明深色
   - 字体大小：14px～16px
   - 字重：600

3. 为不同类型设置轻微的颜色区分，但不要改变整体深空配色：

4. 分类颜色只用于：
   - 分类标题边框
   - 分类标题文字
   - 少量装饰线或小图标

不要给整个区域添加过强的彩色背景，也不要让三类区域变成完全不同的风格。

二、行星名称的设计

请重新设计每个行星下方的名称标签，使其更容易识别，同时保持当前页面的高级感。

每个行星名称标签包含：

- 行星名称
- 可选的序号，例如“01”
- 可选的简短英文名称或类型信息

建议默认只显示中文名称和序号，不要显示过多文字。

示例：

01 水星
02 金星
03 地球
04 火星
05 木星
06 土星
07 天王星
08 海王星

名称标签样式要求：

1. 使用深色半透明胶囊标签：
   background: rgba(8, 14, 32, 0.82)

2. 使用细边框：
   border: 1px solid rgba(148, 163, 184, 0.3)

3. 中文名称字号：
   font-size: 14px～16px

4. 序号字号：
   font-size: 11px～12px
   color 使用低饱和蓝色或灰色

5. 标签位置保持在行星下方，并与行星主体保持 12px～18px 的间距。

6. 行星名称标签不能遮挡行星图片或轨道。

7. 标签应具有轻微阴影：
   box-shadow: 0 4px 16px rgba(0, 0, 0, 0.2)

三、行星名称的 hover 状态

鼠标悬停在行星或名称标签上时：

1. 行星轻微放大：
   transform: scale(1.05)

2. 行星名称标签向上移动 3px。

3. 名称标签边框变亮。

4. 增加轻微的蓝色光晕。

5. 过渡动画使用：
   transition: all 0.3s ease

不要使用快速闪烁、强烈发光或持续跳动的动画。

四、行星名称的选中状态

点击某个行星后，该行星进入选中状态。

选中状态要求：

1. 行星名称标签变为金色强调：

   border-color: #F5C542;
   color: #FFE58A;
   background: rgba(69, 50, 10, 0.72);

2. 在名称标签左侧或上方增加一个小型选中标识，例如：
   - 小圆点
   - 细金色短线
   - 小型星标

3. 被选中的行星增加柔和金色光晕，但不要过亮：

   box-shadow:
   0 0 0 1px rgba(245, 197, 66, 0.45),
   0 0 24px rgba(245, 197, 66, 0.25);

4. 未被选中的行星可以轻微降低透明度，但不能完全变暗，确保仍然可见。

5. 键盘操作也应支持选中状态，并添加 aria-pressed 属性。

五、点击后的下方信息面板

请保留当前页面底部的信息区域位置，不要新增侧边栏，也不要改变主要行星布局。

点击行星后，在行星展示区域下方更新信息面板。

信息面板建议设计为一个横向知识卡片，具有以下结构：

左侧：
- 行星小图标或缩略图
- 行星名称
- 行星类型

中间：
- 一句简短的核心介绍

右侧：
- 2～4 个关键数据

建议结构：

[行星缩略图]  土星
             类木行星
             拥有太阳系中最显著的行星环系统

             距离太阳：9.58 AU
             公转周期：29.5 年
             自转周期：约 10.7 小时

如果当前项目结构不适合三列布局，也可以采用上下结构：

第一行：
[行星名称] [行星类型标签]

第二行：
行星简介

第三行：
[距离太阳] [公转周期] [自转周期]

六、信息面板视觉样式

信息面板整体保持当前深色宇宙风格，但比普通容器更突出。

建议样式：

- max-width: 1180px
- width: calc(100% - 32px)
- margin: 32px auto 0
- padding: 22px 28px
- border-radius: 18px
- background: linear-gradient(
    135deg,
    rgba(18, 31, 62, 0.88),
    rgba(8, 16, 36, 0.92)
  )
- border: 1px solid rgba(56, 189, 248, 0.38)
- box-shadow: 0 12px 40px rgba(0, 0, 0, 0.25)

信息面板顶部增加一条很细的装饰线，使用蓝色到金色的渐变：

background: linear-gradient(
  90deg,
  #38BDF8,
  #6474FF,
  #F5C542
);

七、信息面板内容层级

请严格区分以下层级：

1. 行星名称：
   - 字号 22px～28px
   - 字重 700
   - 使用白色或接近白色

2. 行星类型：
   - 字号 12px～14px
   - 胶囊标签样式
   - 使用分类对应颜色

3. 行星简介：
   - 字号 14px～16px
   - 颜色 #B9C2D5
   - 行高 1.7
   - 最多显示两行

4. 数据标签：
   - 标签名称字号 12px
   - 数据内容字号 15px～16px
   - 数据内容使用浅蓝色或金色强调

八、信息面板切换动画

点击不同的行星时，信息面板内容需要平滑切换。

要求：

1. 不要让整个页面重新刷新。
2. 内容切换时使用淡入和轻微上移动动画。
3. 动画时长建议为 250ms～350ms。
4. 如果用户开启了 prefers-reduced-motion，则关闭动画。
5. 信息面板高度变化时要尽量平滑，避免页面突然跳动。
