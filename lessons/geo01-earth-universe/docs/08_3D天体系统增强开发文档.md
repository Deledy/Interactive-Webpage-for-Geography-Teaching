# 开发文档：3D 多级天体系统漫游模块

> 本文件是 `05_开发文档.md` 中 **P2「3D 多级天体系统模型（卫星绕行星）」** 的落地设计。
> 定位：在 geo01《地球的宇宙环境》内新增一个增强模块（暂编号 **M10**），承接 M4（天体系统层级）与 M5（太阳系与八大行星），
> 把 M4 的「静态嵌套圆环示意图」升级为「可点击导航 + 可自由漫游的多级天体系统」。
> 可行性依据：ORBIT 项目源码移植验证（见本课 `06_资源引用.md` 登记项），技术底座已具备。

---

## A. 背景与本模块定位

- 现状：M4 用 SVG 嵌套圆环表达四级层级，能"看懂"，但不能"看进去"；M5 只有太阳系一个系统，缺"卫星绕行星"这一级。
- 本模块目标：让学生**在同一页内逐级穿行**，亲手看到
  1. 卫星绕行星转 → 构成**行星系统**；
  2. 行星绕恒星转 → 构成**恒星星系**（且能切换到其他真实恒星）；
  3. 恒星绕星系中心转 → 构成**星系**；
  4. 星系之外还有大量星系 → 构成**可观测宇宙**。
- 不替代 M4/M5：M4 的圆环图仍是"结构速览"，M5 的 2D SVG 仍是保底。本模块是**第三层增强视图**。

## B. 教学目标与口径（高中必修一）

### B1. 层级口径（严格按教材四级）

| 层级 | 天体系统 | 本模块呈现 |
|---|---|---|
| 第 1 级 | 可观测宇宙 | 星系群全景 + 观测边界示意 |
| 第 2 级 | 银河系 | 旋臂盘面 + 恒星绕银心 |
| 第 3 级 | 太阳系 | 八大行星绕太阳 |
| 第 4 级 | 地月系 | 月球绕地球 |

**行星系统（木星系 / 土星系）属于太阳系内部的次级系统，不得与太阳系并列为一级**，页面上必须标注为「拓展观察」。

### B2. 必须更正的 5 处表述（教学准确性）

| # | 常见错误表述 | 正确表述 |
|---|---|---|
| 1 | 银河系有恒星"上万亿颗" | **上千亿颗**（约 1000~4000 亿），教材口径"约有一两千亿颗" |
| 2 | 太阳"绕着某一个天体"转 | 太阳**绕银河系中心（银心）公转**，周期约 2.3 亿年；银心方向有人马座 A\*，**不可说成"太阳绕黑洞转"** |
| 3 | "河外星系中还有很多其他星系" | 河外星系**即**银河系以外的星系，表述应为"银河系之外还有许多星系" |
| 4 | "每颗恒星都有行星围绕" | "**许多**恒星都有自己的行星系统"（行星普遍存在，但非全部） |
| 5 | 用"行星系统"同时指 卫星绕行星 与 行星绕恒星 | 分两级：**卫星绕行星 = 行星系统**；**行星绕恒星 = 恒星星系** |

### B3. 易错点必须写进文案

- **可观测宇宙是"人类观测能力的边界"，不是"宇宙的边界"**；宇宙本身没有已知边界。
- 全部 3D 画面标注「**非等比示意**」：位置、大小、颜色为可看性做了艺术化处理，不等于真实比例。
- 河外巨行星等被原作标注为「虚构/示意」的天体**必须剔除或显著标注**。

## C. 内容层级设计（5 站 + 1 个转场）

```
站1 地月系 ──→ 站2 太阳系 ──→ 站3 其他恒星行星系 ──→ 站4 银河系 ──→ 站5 河外星系 ──[转场]──→ 宇宙尺度
   月球绕地球     八大行星绕太阳     切换恒星看系外行星     太阳绕银心     14 座真实星系      独立视图
   (+木星系/土星系：拓展观察，可开关)
```

| 站 | 教学点 | 交互 | 降级 |
|---|---|---|---|
| 1 地月系 | 卫星绕行星 → 行星系统 | 按钮飞入；可展开木星系/土星系（拓展） | 静态图 + 文字 |
| 2 太阳系 | 行星绕恒星 → 太阳系 | 复用 M5 的 3D；点击行星出信息卡 | 复用 M5 的 2D SVG |
| 3 其他恒星 | 行星系普遍存在 | 恒星列表切换（TRAPPIST-1 / 开普勒-186 / HR 8799…），进入后可见行星绕恒星 | 静态对比图 |
| 4 银河系 | 恒星绕银心 → 星系 | 拉远看盘面 + 太阳系绕银心轨迹 | 静态盘面图 |
| 5 河外星系 | 银河系并非唯一 | 切换 14 座星系；点明"与银河系同级别" | 静态图集 |
| 转场 → 宇宙尺度 | 可观测宇宙 | **独立视图**，非连续缩放（见 E3） | 韦布深空场图 + 文案 |

## E. 技术方案

### E1. 骨架

沿用 ORBIT 的渲染三件套（对数深度缓冲 → 对数相机 → 按距离自动显隐），保证跨尺度不闪烁。
关键红线：**从月球（≈1 单位）到可观测宇宙（≈4.5×10⁷ 单位）跨约 8 个数量级，单场景连续缩放必然失真**，因此：

### E2. 卫星系统的尺度处理（N1 的技术难点）

木卫轨道半径 / 木星半径 ≈ 5~20，与日地距离量级完全不同，**不能塞进太阳系全局尺度**（否则木卫一会被压进行星内部）。
做法：为木星系、土星系各建**独立局部坐标系**（照 ORBIT 处理深空系统的 `world.getPosition(id)` 思路），点击时以转场进入。

### E3. 宇宙尺度的处理（N2 的关键决策）

仙女座 M31 在 ORBIT 中为 240000 单位 ≈ 250 万光年；可观测宇宙半径 465 亿光年 → 需约 4.5×10⁷ 单位。
**决策：不做连续缩放到可观测宇宙**，改为**独立视图 + 转场**（以韦布深空场图为底 + 尺度阶梯文案），避免为最后一级拖垮整个渲染精度。

### E4. 双模式

| 模式 | 相机行为 | 适用 |
|---|---|---|
| 课堂导航（默认） | 底部按「天体系统层级」排列的按钮，点击平滑飞向；隐藏自由漫游控件 | 讲授、投屏 |
| 自由探索（开关） | 启用滚轮连续缩放与焦点自动切换 | 课后自学 |

> 自由探索需重写 ORBIT 的相机装配层（它与原作 `world` 强耦合），是工作量最大的单项。

## K. v1.1 新增需求（本次评审后追加）

### K1. 距离驱动的层级导航（替代「截图式」按钮换层）

**问题**：v1.0 用「焦点 id」决定当前层级，导致滚轮只缩放、不换层。

**做法**：还原 ORBIT `core/camera.js` 的模型（已核对源码）：

| 机制 | 说明 |
|---|---|
| 层级由距离反推 | `stage()` 按「相机到视点距离」判定：`>2600` → 银河系级；`>max(28, r×10)` → 太阳系级；否则地月系级；更远（`>200000`）→ 河外星系图鉴 |
| 视点多尺度漂移 | `trackingCenter(distance)` 让视点随距离连续过渡：本天体 → 太阳系中心 → 银心 → 图鉴中心（各段用 `smooth(a,b,distance)` 混合） |
| 分层淡入淡出 | `updateWorldVisibility` 按距离控制各层天体与轨道线的显隐/透明度 |
| 跨层即刷新 UI | 仅在层级发生变化的瞬间更新架构图高亮、尺度轴游标与讲解文案（附 toast 提示） |

按钮（架构图节点 / 尺度轴刻度）退化为「设定目标层并平滑飞达」的快捷方式，与滚轮不冲突。

### K2. 银河系运动的正确表现

**v1.0 的问题**：把太阳系整组沿银心轨道平移，且是全局常开 → 在 7.8 单位视距的地月系里等于每秒掠过上百个画面（显示错位 + 剧烈抖动）。

**核实 ORBIT 源码后的两个事实**：
1. ORBIT 的银河系点云**完全静止**（仅 `position` + `rotation.x = 0.13`），并没有绕银盘自转；
2. ORBIT 的「站 4」效果来自一个**隔离区域**的 `kind:'trajectory'` 演示：用 `绕日圆轨道位置 − uForward × age × uGalactic` 生成螺旋拖尾，源码注释明确写着它「是局部直线参考系，**不是**太阳完整银心轨道的模型」。

**本模块采用**（K 决策 6）：**银河盘整体缓慢自转 + 太阳随盘被带走**。
- 实现：银河点云挂在一个绕银盘法线自转的组里（`rotation.x` 保持盘面倾角，`rotation.y` 缓慢累加）；
- 太阳在银盘局部坐标里方位角固定、半径 ≈ 银盘半径一半（对应真实「距银心约 2.6 万光年 / 银盘半径约 5 万光年」），由盘的旋转带出世界坐标；
- **自转只在「银河系 / 河外星系」层级播放**，离开即冻结 —— 这样地月系、太阳系视距下画面完全静止，从根上消除抖动；
- 保留太阳的银心轨道圆（半径 = 太阳的银心距离）。

**必须写进文案的纠偏**（否则该示意本身会误导）：
- 真实银河系是**较差自转**（内侧快、外侧慢），不是刚体整体旋转；
- **旋臂不是物质结构，而是密度波**，恒星穿过旋臂时被聚集，才显得旋臂在转；
- 太阳轨道还叠加**垂直盘面的上下振荡**（周期约 6000 万年）。

### K3. 天体系统架构图（教材式树状图 + 底部对数尺度轴）

### K5. 近邻恒星的「距离可见 + 点击飞达」（对齐 ORBIT，v1.1 追加）

**背景核实**：ORBIT 原项目确实存在该机制 —— 深空恒星与太阳系同处一个场景、同一张 `bodies` 表
（`scene.js`），位置就摆在太阳附近几千单位（`deep-space-catalog.js`），可见性为**距离驱动**
（`deep-space-bodies.js`：`distance < body.r × 900`），并用 raycast 拾取后 `flyTo`（`picking.js`），
另有名称标签（`labels.js`）。

**结论**：本项目采纳该机制，替换 v1.0 的"层级门控"。

- **可见性**：`star-systems.ts` 改为距离驱动 —— `distance < body.r × 900`（恒星）/ `× 320`（行星）即显形，
  不再依赖 `stage === 'stars'`。于是"从太阳系一路缩放拉远，近邻恒星自然浮现"。
- **点击飞达**：新增 raycast 拾取（`main.ts`），对**当前可见**的恒星 / 行星 / 卫星命中后 `flyTo`；
  区分"点击"与"拖动/长按"。
- **名称标签**：进入银河系层级（`galaxy`）后，恒星名以「圆点 + 名称」形式随相机投影显示在屏幕
  （`#starlabels`），点击标签同样飞达。**关键**：标签**不以恒星本体是否已按距离显形为前提**
  —— 与 ORBIT `labels.js` 一致（其条件是 `mode === 'galaxy'`），因此"进入银河系即可看到太阳
  附近一圈恒星的名字"。标签会做屏幕边界、互相压字与 UI 占位的避让。
- **入口一致**：恒星本体 / 标签 / 架构图节点 / 底部尺度轴 / 站点目标条，全部走同一个 `jumpTo`。

**恒星清单（扩充后 10 颗，均为「目前已确认存在行星」的真实恒星）**：
比邻星、TRAPPIST-1、开普勒-186、开普勒-22、HR 8799（原有 5 颗）+
**巴纳德星**（2024 确认 b）、**蒂加登星**（宜居带双行星 b/c）、**天苑四**（木星类似体 b）、
**飞马座 51**（1995 年首颗类太阳恒星的系外行星）、**开普勒-452**（"地球的大表哥" b）。

> 事实来源：NASA Exoplanet Archive、ESO / NASA 官方发布。搬入主项目时须**登记到 `docs/06_资源引用.md`**。
> 坐标仍为**非等比示意**（压缩到太阳附近数千～上万单位），真实距离见各恒星 `distance` 字段。

### K6. 删除"太阳绕银心的轨道圆"（v1.1 追加）

- 原 v1.1 在银盘内画了一条半径 = 太阳银心距离的闭合圆环（`galacticRing`），表示"太阳的银心轨道"。
- **删除理由**：该圆环与 K2 的模型（银河盘整体自转、太阳随盘被带走）自相矛盾，且会让人误以为
  太阳/地球沿一条看得见的轨道绕银心运行 —— 与真实银河系（较差自转、旋臂为密度波、轨道并非
  可视圆环）不符，属**错误信息**。
- 处理：移除 `world.ts` 中 `galacticRing` 的创建与显隐逻辑（`makeOrbit` 导入一并清理）。
  太阳位置仍由 `galaxy.solarMarker`（"太阳系·你在这里"标记）指示。
