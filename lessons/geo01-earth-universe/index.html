天体判别 · 流星案例

判断一个物体是不是天体，看三条标准：是物质不是现象、位于地球大气层之外、是独立个体。跟随流星案例动画，一步一步验证这三条标准。

流星现象动画演示 · 流星体在太空中漂浮 → 进入大气层摩擦燃烧成流星 → 未燃尽落至地面成陨石
（启用 JavaScript 后可观看循环动画演示）

判别三条件

  • 是物质是物质，不是现象
  • 大气层之外位于地球大气层之外
  • 独立个体独立运行，不是某一天体的一部分

流星现象发生在大气层内，是现象不是天体；落到地面的陨石，也不是天体。

天体系统层级

天体之间相互吸引、相互绕转，构成不同级别的天体系统。从大到小依次为：可观测宇宙 → 银河系 → 太阳系 → 地月系。

地月系：地球与月球相互吸引、相互绕转。同级别案例：火卫一绕火星运行（火星的卫星系统）太阳系：太阳与八大行星等天体相互绕转。同级别案例：半人马座 α 星系（比邻星所在的三合星系统）银河系：太阳系等上千亿个恒星系统组成的巨大星系。同级别案例：仙女座星系（河外星系）可观测宇宙：银河系等数千亿个星系构成的可观测范围。人类目前所能观测到的宇宙边界

MODULE 06 · SOLAR SYSTEM

模块 07

行星的运动特征

八大行星绕日公转方向一致（自西向东）、轨道近似圆形、轨道面几乎位于同一平面，分别体现同向性、近圆性与共面性。

同向性

八大行星绕日公转的方向都是自西向东。

近圆性

行星绕日公转的轨道近似圆形。

共面性

行星轨道面几乎位于同一平面上。

MODULE 07 · PLANETARY MOTION

模块 08

地球存在生命的原因

地球的特殊性来自外部条件（太阳与宇宙环境）与自身条件（温度、大气、液态水）的共同作用。以下将外部条件与自身条件分开呈现。

外部条件

太阳处于壮年
光照稳定，生命演化连续
大小行星各行其道
互不干扰，宇宙环境安全

自身条件

日地距离适中、自转公转周期适宜
温度适宜，水以液态存在
地球体积、质量适中
引力足够吸引大气，经漫长演化形成适宜大气
原始地球内部升温产生水汽
水汽逸出地表成云致雨，汇聚成海，孕育生命

外部条件 + 自身条件共同作用 → 地球成为目前已知唯一适宜生命存在的星球。
