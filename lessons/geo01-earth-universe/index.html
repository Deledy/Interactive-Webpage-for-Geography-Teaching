判断一个物体是不是天体，看三条标准。

流星现象动画演示 · 流星体在太空中漂浮 → 进入大气层摩擦燃烧成流星 → 未燃尽落至地面成陨石
（启用 JavaScript 后可观看循环动画演示）

判别三条件

同时满足以下三条，才是天体

  • 是物质，不是现象 有质量、占空间的物质实体才可能是天体。
  • 位于地球大气层之外 天体在太空（大气层之外）运行。
  • 是独立个体 独立运行、有自身的运动轨道，不是某一天体的附属部分。

综合判断

下列哪些是天体，哪些不是天体？

  • 流星体 是天体
  • 流星现象 不是天体
  • 陨石 不是天体

天体系统层级

天体之间相互吸引、相互绕转，构成不同级别的天体系统。从大到小依次为：可观测宇宙 → 银河系 → 太阳系 → 地月系。

MODULE 06 · PLANETARY MOTION

模块 07

地球的普通性和特殊性

无论是从距日远近、自身的体积，还是从公转方式来看，地球都只是太阳系中一颗普通的行星。然而，地球又是太阳系中一颗特殊的行星。

运动特征

绕日公转的方向、轨道形状与轨道面，与其余七颗行星一致。

  • 同向性
  • 近圆性
  • 共面性

结构特征

体积、质量与类地行星相近，与金星最为接近。

与类地行星同量级

所以，地球是一颗普通的行星。

然而——

特殊性

地球是太阳系八大行星中目前已知唯一存在高级智慧生命的星球。

所以，地球其实又是一颗特殊的行星。

MODULE 07 · EARTH: ORDINARY & SPECIAL

模块 08

地球存在生命的原因

地球的特殊性来自外部条件（太阳与宇宙环境）与自身条件（温度、大气、液态水）的共同作用。以下将外部条件与自身条件分开呈现。

外部条件

太阳处于壮年

光照稳定生命演化连续

大小行星各行其道

互不干扰宇宙环境安全

自身条件

日地距离适中、自转公转周期适宜

温度适宜水以液态存在

地球体积、质量适中

引力足够吸引大气经漫长演化形成适宜大气

原始地球内部升温产生水汽

水汽逸出地表成云致雨汇聚成海孕育生命

外部条件 + 自身条件共同作用 → 地球成为目前已知唯一适宜生命存在的星球。
