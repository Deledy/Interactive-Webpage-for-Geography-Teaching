模块 01

宇宙概念

宇宙是空间与时间的统一体，无边无际、无始无终；它是物质性的、运动性的，约 137 亿年前起源于一次大爆炸。

四方上下曰宇，往古来今曰宙

宇宙是所有时间、空间和物质的总和

天体卡片档案

天体是宇宙中物质的存在形式。

按来源，天体可分为 自然天体 与 人造天体 两大类。

猫眼星云 NGC 6543 · 行星状星云

星云

由气体和尘埃组成的呈云雾状外表的天体，主要物质是氢。

组成气体和尘埃，主要物质是氢

特点

  • 呈云雾状外表

星云是恒星的摇篮，亦是归宿——恒星在其中诞生，消亡后又化作新星云，循环往复。

比邻星 离我们第二近的恒星

恒星 易错

由炽热气体组成的、自身能发出光和热的球形天体。

组成炽热气体（氢和氦）

特点

  • 体积、质量较大
  • 自身能发出光和热

太阳是离我们最近的恒星，比邻星是除太阳外离我们最近的恒星。

行星

在椭圆轨道上绕恒星运行的、近似球状的天体。

组成岩石、气体等（如八大行星）

特点

  • 行星的质量比恒星小
  • 本身不发光，靠反射恒星的光而发亮

我们看到的行星亮光，其实是反射的太阳光。

卫星

环绕行星运转的天体。卫星的大小差别很大。

组成岩石、冰等

特点

  • 绕行星公转
  • 本身不发光
  • 依靠反射恒星的光而发亮

月球是地球的天然卫星，木卫二是木星的一颗卫星。

在扁长轨道上绕太阳运行的一种质量很小的天体，由冰物质组成。

由人类制造并发射、围绕地球等天体运行的人造天体，用于通信、导航、气象观测与科学研究。

在太空中运行的人造卫星，属于人造天体。

模块 03

天体判别 · 流星案例

判断一个物体是不是天体，看三条标准：是物质不是现象、位于地球大气层之外、是独立个体。跟随流星案例动画，一步一步验证这三条标准。

流星现象动画演示 · 流星体在太空中漂浮 → 进入大气层摩擦燃烧成流星 → 未燃尽落至地面成陨石
（启用 JavaScript 后可观看循环动画演示）

判别三条件

  • 是物质是物质，不是现象
  • 大气层之外位于地球大气层之外
  • 独立个体独立运行，不是某一天体的一部分

流星现象发生在大气层内，是现象不是天体；落到地面的陨石，也不是天体。

模块 05

天体系统层级

天体之间相互吸引、相互绕转，构成不同级别的天体系统。从大到小依次为：可观测宇宙 → 银河系 → 太阳系 → 地月系。

地月系：地球与月球相互吸引、相互绕转。同级别案例：火卫一绕火星运行（火星的卫星系统）太阳系：太阳与八大行星等天体相互绕转。同级别案例：半人马座 α 星系（比邻星所在的三合星系统）银河系：太阳系等上千亿个恒星系统组成的巨大星系。同级别案例：仙女座星系（河外星系）可观测宇宙：银河系等数千亿个星系构成的可观测范围。人类目前所能观测到的宇宙边界

模块 07

行星的运动特征

八大行星绕日公转方向一致（自西向东）、轨道近似圆形、轨道面几乎位于同一平面，分别体现同向性、近圆性与共面性。

同向性

八大行星绕日公转的方向都是自西向东。

近圆性

行星绕日公转的轨道近似圆形。

共面性

行星轨道面几乎位于同一平面上。

模块 08

地球存在生命的原因

地球的特殊性来自外部条件（太阳与宇宙环境）与自身条件（温度、大气、液态水）的共同作用。以下将外部条件与自身条件分开呈现。

外部条件

太阳处于壮年
光照稳定，生命演化连续
大小行星各行其道
互不干扰，宇宙环境安全

自身条件

日地距离适中、自转公转周期适宜
温度适宜，水以液态存在
地球体积、质量适中
引力足够吸引大气，经漫长演化形成适宜大气
原始地球内部升温产生水汽
水汽逸出地表成云致雨，汇聚成海，孕育生命

外部条件 + 自身条件共同作用 → 地球成为目前已知唯一适宜生命存在的星球。
