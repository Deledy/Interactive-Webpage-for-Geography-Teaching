# assets/ 资源目录

本目录存放单课特有的本地静态资源，按类型分目录存放：

| 子目录 | 用途 |
| --- | --- |
| `images/` | 本地图片（示意插图、课程配图等） |
| `icons/` | 图标文件（SVG / PNG） |
| `videos/` | 教学视频 |
| `fonts/` | 本地字体文件 |

## 使用说明

1. 资源文件一律放在 `assets/` 下，不要在 `css/` 或 `js/` 中混放。
2. 页面内引用使用相对路径，例如 `assets/images/xxx.png`。
3. 可被多课复用的公共资源请抽离到根目录 `shared/assets/`。
4. 构建发布时，`assets/` 会随其他源码一起复制到 `dist/`。
