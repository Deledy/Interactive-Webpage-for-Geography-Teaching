请根据当前项目中的开发说明书开始实现教学网页。

## 目标
将本节地理课内容实现为一个可运行的 HTML 教学网页，优先完成 MVP，保证教学目标清晰、页面结构合理、核心交互可用。

## 任务要求
1. 先阅读以下文件：
   - AGENTS.md
   - agents/current_task.md
   - 开发说明书.md

2. 按照开发说明书中的要求实现网页，不要自行扩展无关功能。

3. 开发顺序如下：
   - 先搭建页面骨架
   - 再实现核心教学内容
   - 再实现核心交互
   - 再实现必要的可视化
   - 最后进行样式统一和基础适配

4. 优先实现 P0 功能，P1/P2 功能如时间不足可暂缓。

5. 技术原则：
   - 优先使用原生 HTML / CSS / JavaScript
   - 只有在开发说明书明确要求时才引入外部库
   - 尽量保持结构简单、代码清晰、便于修改
   - 尽量支持手机端浏览
   - 尽量保证离线可用

6. 如果开发说明书中存在不明确或冲突的地方：
   - 先列出问题
   - 不要擅自臆造实现
   - 等待确认后再继续

## 输出要求
1. 先输出你的实现计划
2. 再逐步生成代码
3. 完成后总结：
   - 已实现功能
   - 未实现功能
   - 可能需要优化的地方
   - 是否存在报错或风险

## 额外要求
- 重点保证教学清晰度，不追求炫技。
- 页面要适合教师课堂讲授，也要适合学生自主浏览。
- 如需降级，请优先保证核心教学流程完整。
