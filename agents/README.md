# agents/ Agent 工作流目录

本目录集中存放"教学网页生产工作流"（Agent 工作流）的全部内容。Agent 编排由**项目外的 Agent 应用**执行，本目录只提供角色提示词、交接模板与任务输入/输出，项目本地不运行任何 AI 编排逻辑。

> 项目级规则 `AGENTS.md` 位于根目录（供 IDE/Agent 工具自动加载），本目录是它的配套素材。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `current_task.md` | 当前任务输入模板（写新课时先在此填写需求，是工作流起点） |
| `prompts/` | 5 个角色提示词：教育教学设计、页面设计、技术实现、总控、开发文档 |
| `templates/` | 各阶段交接格式模板（教学设计/页面设计/技术实现/总控/开发文档） |
| `output/` | 工作流分析输出（如架构分析报告） |

## 角色清单与边界

| 角色 | 提示词 | 职责 | 输出 |
| --- | --- | --- | --- |
| 教育教学设计专家 | `prompts/地理教育教学专家.md` | 教学结构、教学目标与教学价值判断 | 教学设计交接包 |
| 页面设计专家 | `prompts/页面设计agent.md` | 页面布局、视觉层次与学习体验 | 页面设计交接包 |
| 技术实现专家 | `prompts/技术实现agent.md` | 技术可行性、库选择与实现路径 | 技术实现交接包 |
| 总控专家 | `prompts/总控agent.md` | 协调、裁剪、决策和范围控制 | 总控摘要 |
| 开发文档专家 | `prompts/开发文档agent.md` | 整理成 AI 编程工具可执行的说明书 | 开发文档 |

**边界约定**：所有 Agent 只负责生成开发报告（`lessons/<课>/docs/01~05`），**不负责代码实现**；代码由 AI 编程工具按开发文档执行。

## 使用流程

1. 在 `agents/current_task.md` 填写新课需求（可写乱，随后由 Agent 整理）。
2. 让 Agent 依次扮演 5 个角色，各阶段产物写入 `lessons/<课>/docs/01~05`。
3. 将 `05_开发文档.md` 交给 AI 编程工具实现代码。
4. 课程按 `lessons/<课>/lesson.json` 登记（书名、章节、资源、构建模式）。

## 模板说明

- 各阶段交接包有独立格式模板（`templates/`）。
- 单课 docs/ 的 `current_task.md` 是**该课任务输入存档**（`agents/current_task.md` 是通用模板）。
