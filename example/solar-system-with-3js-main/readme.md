# 🌌 Solar System with Three.js

An interactive 3D Solar System simulation built using **Three.js**, showcasing the Sun, planets, orbital motion, lighting, and realistic space visualization. This project demonstrates modern 3D web development concepts using JavaScript and WebGL.

---

## 🚀 Features

- 🌞 Realistic 3D Sun and planets
- 🪐 Planetary orbital animation
- 🌍 Interactive 3D scene using Three.js
- 💡 Dynamic lighting and shadows
- 🎥 Camera controls for scene exploration
- 🌌 Space-themed environment
- 📱 Responsive web experience
- ⚡ Fast and lightweight

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/pranjal3007/solar-system-with-3js.git
```

### Navigate to the project

```bash
cd solar-system-with-3js
```

### Run the project

Open `index.html` using **Live Server** in VS Code or run a local server:

```bash
python -m http.server 8000
```

Visit:

```
http://localhost:8000
```
