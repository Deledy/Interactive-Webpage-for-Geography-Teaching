# 天体表面纹理资源引用登记

本文件登记 `example/orbit-feasibility` 中所有**非原创**表面纹理。约束（对应《太阳系有卫星行星系统绘制方案》第 2 节）：

1. 只允许使用官方观测产品（USGS Astrogeology、NASA/JPL、ESA 任务团队）；**禁止程序化/虚构地表纹理**；
2. 每张图必须可追溯到具体产品名与许可；
3. 全球影像不足的天体（C 级）**不生成贴图**，仅按实测几何反照率给纯色。

规格：等距圆柱投影（经度 0° 在左边缘），卫星 1024×512、行星 2048×1024，sRGB 8bit。

### 处理步骤（一次性、可复现）

1. 在 USGS Astrogeology `search` 门户按"观测产品"列的名称检索，下载 GeoTIFF/JP2；
2. 重投影为等距圆柱（经度 0° 在左边缘）；
3. 降采样到 1024×512，8bit sRGB，JPEG q85；
4. B 级按该天体**实测中值反照率**填充未观测区，不做纹理修复、不补造地貌；
5. 覆盖范围与波段写入本篇登记表，并在界面讲解卡"数据来源"一栏同步显示。

**已验证的免重投影捷径**（本次月球与伽利略四卫星即用此法，无需 GDAL）：

- USGS 每个产品页都附带可直接下载的 **1024px 宽等距圆柱预览图**（`full.jpg` 或 `*_1024.jpg`），尺寸恰为 1024×512；
- 页面底部 "Access Constraints" 已明确标注 public domain，可直接登记引用；
- 因此流程可简化为：定产品 → 取预览图 → 存为 `assets/textures/moons/<id>.jpg`，构建时由 `import.meta.glob` 自动接管，无需改代码。

**重投影管线（`scripts/tif-to-equirect.py`）**

很多官方产品只提供 GeoTIFF，且投影为 Mercator / Polar Stereographic / Sinusoidal。脚本用 rasterio（内置 GDAL 3.12）统一转成 2:1 等距圆柱：

```powershell
# 看元数据（尺寸、波段、CRS、天体半径是否可从 CRS 解析）
python example/orbit-feasibility/scripts/tif-to-equirect.py Phobos_Viking_Mosaic_40ppd_DLRcontrol.tif --info

# 转成 1024×512 贴图（高度自动取宽度一半）
python example/orbit-feasibility/scripts/tif-to-equirect.py <input.tif> `
  --out example/orbit-feasibility/assets/textures/moons/<id>.jpg --width 1024

# 高清版：2048×1024
python example/orbit-feasibility/scripts/tif-to-equirect.py <input.tif> --out ... --width 2048
```

行为约定：

- 天体半径从 CRS 的 `R`/`a` 参数读取（行星体不能用地球半径，否则经度会被压缩数倍）；读不到时退回地球半径并在输出中标记 `radius_known: false`；
- 已是地理坐标（Simple Cylindrical / longlat）的产品走"直接重采样"，不做多余重采样损失；
- 非 2:1 的"近全球"产品（如 Titan）居中放入 2:1 画布，空带按有效像元均值填充；
- Mercator 无法覆盖 ±90°，极区空带同样按均值填充，并在登记表注明；
- 输出 JPEG q88，落盘即被 `import.meta.glob` 自动接管，无需改代码。

已用三组合成 GeoTIFF 验证：地理坐标直通、Mercator→等距圆柱（与直通结果逐像素对比，除极区外一致）、非 2:1 补齐。

**尚未就位的原因（共 6 颗，已确认无法靠重投影解决）**：逐产品核查 USGS 全站搜索结果后确认——土卫一 Mimas 只有 `mimas_pictorial_map` / `mimas_airbrush_shaded_relief` / `mimas_voyager_image_control_network`；天卫一~五只有 `*_voyager_image_control_network` 与 pictorial map；USGS 根本没有这些天体的全球**影像**拼图（`q=uranus`、`q=saturn` 也无行星级拼图）。pictorial / airbrush 是带图框注记的地形渲染图，不是观测影像，按本方案的分级规则不得作为贴图。

因此重投影管线不会自行增加这 6 颗；它的价值在于：① 把已有 12 颗的官方 TIF 升级到 2048 分辨率；② 一旦你提供 PDS / ESA / 自建拼图的 GeoTIFF，一条命令即可接入。这 6 颗在补图前按实测反照率纯色显示，界面会标注"底图待就位"。
